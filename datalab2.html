TAdd와 UAdd는 bit 수준 동작이 동일

  • -bit 두 수의 진짜 합은 bit → carry를 버리고 bit만 남김

Fractional binary와 IEEE 754

  • 소수점 오른쪽 bit는 자리
  • 한계 ① 꼴만 정확히 표현 가능 ② 범위 제한

IEEE 형식 :

  • s : sign bit (MSB)
  • exp field e : E를 encoding (E와 같지 않음)
  • frac field f : M을 encoding (M과 같지 않음)

single (32-bit) : s 1, exp 8, frac 23, bias 127

double (64-bit) : s 1, exp 11, frac 52, bias 1023

extended (Intel, 80-bit) : s 1, exp 15, frac 63 또는 64

Normalized · Denormalized · Special

Normalized : exp가 000…0도 111…1도 아님

  • E = exp − Bias, M = 1.f (implied leading 1) → 일반적인 수

Denormalized : exp = 000…0

  • E = 1 − Bias, M = 0.f (implied leading 0) → 0 (f=0, +0과 −0 구분), 0에 아주 가까운 수 (gradual underflow)

Special : exp = 111…1

  • f=0 → ±∞ (overflow, 1.0/0.0), f≠0 → NaN (sqrt(−1), ∞−∞, ∞×0)

Bias ( = exp bit 수)

  • single : exp 1…254 → E = −126…127
  • double : exp 1…2046 → E = −1022…1023

normalized M은 → 맨 앞 1을 저장하지 않으므로 1 bit를 공짜로 얻음

denorm의 E가 가 아니라 인 이유 : 가장 큰 denorm과 가장 작은 normalized 사이가 끊김 없이 이어지게 하려고

  • E = 13 → exp = 13 + 127 = 140 = 10001100

손계산 7 : Tiny float (8-bit)

형식 : s 1 bit, exp 4 bit (bias 7), frac 3 bit → IEEE와 같은 규칙

  • denorm E = 1 − 7 = −6 → 값 =

s exp frac : E, 값

  • 0 0000 000 : E −6, 0 (zero)
  • 0 0000 001 : E −6, 1/8 × 1/64 = 1/512 (0에 가장 가까운 수)
  • 0 0000 111 : E −6, 7/8 × 1/64 = 7/512 (가장 큰 denorm)
  • 0 0001 000 : E −6, 8/8 × 1/64 = 8/512 (가장 작은 normalized)
  • 0 0110 111 : E −1, 15/8 × 1/2 = 15/16 (1보다 작은 수 중 가장 가까운 수)
  • 0 0111 000 : E 0, 1
  • 0 0111 001 : E 0, 9/8 (1보다 큰 수 중 가장 가까운 수)
  • 0 1110 111 : E 7, 15/8 × 128 = 240 (가장 큰 normalized)
  • 0 1111 000 : +∞ (special)

가장 큰 denorm 7/512 → 가장 작은 normalized 8/512 : 1/512 간격으로 매끄럽게 이어짐 (denorm E = 1 − Bias 덕분)

슬라이드 표의 0 0111 110 / 0 0111 111 (E=7, 224·240) 행은 exp가 1110이어야 맞음 (E = 14 − 7 = 7)

가정 : 32-bit two's complement, right shift는 arithmetic, word size 이상 shift는 동작 예측 불가

Floating Point(부동소수점) 문제 접근 아이디어 (보충)

공통 : uf를 세 field로 분리해 놓고 생각

  • sign = uf >> 31, exp = (uf >> 23) & 0xFF, frac = uf & 0x7FFFFF
  • 먼저 exp == 0xFF (NaN/∞), exp == 0 (denorm/0), 그 외 (normalized)로 경우를 나눔

abs : 결과의 의미는 sign bit만 0인 수, 단 NaN 입력은 그대로 돌려줘야 하는지 명세 확인

twice : normalized는 E가 1 커짐 → exp + 1, 결과 exp가 0xFF가 되면 ∞ 처리

  • denorm은 E 고정 → frac을 왼쪽으로 한 칸 (넘치면 자연스럽게 normalized로 넘어감)
  • NaN/∞는 2배해도 그대로

i2f : 0과 TMin을 특별 취급, 절댓값의 최상위 1 위치로 E 결정, 23 bit 넘는 부분은 rounding (round-to-even) 필요

f2i : E < 0이면 0, E가 너무 크면 (int 범위 초과·NaN·∞) 0x80000000, 그 외는 1.f를 E만큼 shift 후 sign 적용

시험 포인트

IEEE : Bias = 2^(k−1) − 1, normalized E = exp − Bias & M = 1.f, denorm E = 1 − Bias & M = 0.f

문제 2

Tiny float (s 1, exp 4 bit bias 7, frac 3 bit)에서 bit pattern 0 0110 010과 0 0000 100의 값을 구하고, 각각 normalized/denormalized를 판별하라.

답

0 0110 010 : exp = 6 → normalized, E = 6 − 7 = −1, M = 1 + 2/8 = 10/8 → 10/8 × 1/2 = 5/8

0 0000 100 : exp = 0 → denormalized, E = 1 − 7 = −6, M = 4/8 → 4/8 × 1/64 = 1/128 (= 4/512)
