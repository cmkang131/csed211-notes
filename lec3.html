    Round-to-Even이 기본인 이유

    나머지 모드는 통계적으로 biased: 양수들의 합이 항상 과대 또는 과소 추정됨. nearest는 버리는 부분이 절반보다 작으면 내림, 크면 올림 → 균등 분포라면 50:50으로 공평. 문제는 정확히 절반일 때 → 결과의 최하위 자리가 짝수가 되도록 → 절반은 올림, 절반은 내림 → 편향 없음.
    • 1.2349999 → 1.23 (절반 미만) · 1.2350001 → 1.24 (절반 초과) · 1.2350000 → 1.24 (정확히 절반, 3은 홀수 → 올림) · 1.2450000 → 1.24 (정확히 절반, 4는 짝수 → 내림)

    Binary Rounding

    • even: LSB가 0 · halfway: rounding 위치 오른쪽 비트들이 100…0
      • 버리는 첫 비트가 0 → 절반 미만 → 버림
      • 버리는 첫 비트가 1이고 뒤에 1이 하나라도 → 절반 초과 → 올림
      • 버리는 첫 비트가 1이고 뒤가 전부 0 → 정확히 절반 → even 쪽으로
