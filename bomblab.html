Bomb Lab(봄 랩) — phase별 disassembly 분석

실습 · gdb로 disassembly를 읽고 각 phase의 입력 조건을 찾아 폭탄을 해제하는 lab — 시험의 asm → C 복원 문제와 풀이 순서가 같음

1풀이 도구와 순서

gdb 명령

  • break explode_bomb — 폭발 직전에 멈춤 (안전장치) · disas (함수 disassemble) · stepi / nexti (한 명령씩)
  • x/s ADDR — 주소의 문자열 읽기 (phase 1) · x/8gx ADDR — 8바이트씩 8개 (jump table) · x/16dw ADDR — 4바이트 10진수 16개 (배열) · info registers
  • asm을 볼 때 순서: (1) 인자가 어떤 register인지 (2) 비교·점프로 만들어지는 구조 (3) 메모리 접근의 offset과 scale — 순서대로 적고 C로 복원

2Phase 1 — 문자열 비교

phase_1:
  sub  $0x8, %rsp
  mov  $0x4024c0, %esi      # 비교할 문자열 주소를 %rsi에
  callq strings_not_equal   # %eax = 같으면 0, 다르면 1
  test %eax, %eax           # %eax = 0이면 ZF=1
  je   0x400f07             # ZF=1이면 폭발 건너뜀
  callq explode_bomb
  • 입력 문자열이 0x4024c0의 문자열과 같아야 함 → x/s 0x4024c0로 읽으면 끝

3Phase 2 — 2배씩 커지는 수열

  callq read_six_numbers        # 정수 6개를 스택에 저장
  cmpl $0x1, (%rsp)             # x1 = 1이어야 함
  je   <phase_2+52>
  ...
  mov  -0x4(%rbx), %eax         # %eax = 이전 원소
  add  %eax, %eax               # %eax = 2 × 이전 원소
  cmp  %eax, (%rbx)             # 현재 원소와 비교
  je   <phase_2+41>            # x_i = 2 × x_(i-1) 여야 함
  add  $0x4, %rbx               # 다음 정수로
  cmp  %rbp, %rbx
  jne  <phase_2+27>            # 끝까지 반복
  • loop 구조: %rbx가 두 번째 정수부터 마지막까지 돌면서 "현재 = 2 × 이전"을 검사
  • x1 = 1이고 2배씩 → 1, 2, 4, 8, 16, 32

4Phase 3 — jump table (switch)

  callq __isoc99_sscanf         # 정수 2개 (개수 %eax로 반환)
  cmp  $0x1, %eax
  jg   <phase_3+39>            # 2개 이상 입력해야 함
  cmpl $0x7, 0xc(%rsp)          # x1 ≤ 7 (unsigned)
  ja   explode_bomb
  mov  0xc(%rsp), %eax
  jmpq *0x402540(,%rax,8)       # x1 값으로 jump table 분기
index (x1)01234567
목적지+64+57+76+88+100+112+124+136
  • x/8gx 0x402540으로 테이블을 읽음 — 각 엔트리가 case 몸통의 주소
  • 각 case는 mov $0, %eax → add/sub 상수의 조합으로 %eax를 만듦. x1 = 4 (+100)면 mov $0x0,%eax; add $0x3ac,%eax → %eax = 0x3ac… 이어서 sub $0x3ac → %eax = 0
  • 마지막에 cmpl $0x5, 0xc(%rsp) (x1 ≤ 5)와 cmp 0x8(%rsp),%eax (x2 = %eax)를 통과해야 함 → x1 = 4, x2 = 0

5Phase 4 — 재귀 함수 func4

  cmpl $0x2,%eax          # sscanf로 정확히 2개
  mov 0xc(%rsp),%eax
  sub $0x2,%eax
  cmp $0x2,%eax           # 0 ≤ x2−2 ≤ 2 → 2 ≤ x2 ≤ 4 (unsigned jbe)
  jbe <phase_4+51>
  ...
  mov 0xc(%rsp),%esi      # 두 번째 인자 = x2
  mov $0x5,%edi           # 첫 번째 인자 = 5
  callq func4
  cmp 0x8(%rsp),%eax      # x1 = func4(5, x2) 여야 함
func4(n = %edi, x = %esi):
  if (n <= 0) return 0
  if (n == 1) return x
  a = func4(n-1, x)
  b = func4(n-2, x)
  return a + x + b
n012345
f(n, x)0x2x4x7x12x
  • func4(5, x2) = 12·x2 이고 x1 = 12·x2 여야 함. 2 ≤ x2 ≤ 4 중 x2 = 2 → x1 = 24

6Phase 5 — 배열을 따라가는 루프

  mov 0xc(%rsp),%eax
  and $0xf,%eax           # x1의 마지막 4 bit만 남김
  cmp $0xf,%eax
  je  explode_bomb        # 1111이면 안 됨
  mov $0x0,%ecx           # %ecx = 합계
  mov $0x0,%edx           # %edx = 반복 횟수
loop:
  add $0x1,%edx
  cltq
  mov 0x402580(,%rax,4),%eax   # %eax = arr[%rax]
  add %eax,%ecx                # 합계에 더함
  cmp $0xf,%eax
  jne loop                     # arr 값이 15가 되면 종료
  cmp $0xf,%edx
  jne explode_bomb             # 반복 횟수 = 15여야 함
  cmp 0x8(%rsp),%ecx           # 합계 = x2 여야 함
  je  <phase_5+104>

  • arr[i]를 다음 index로 삼아 값이 15일 때까지 따라가는 포인터 체이스 — 입력 x1의 하위 4 bit가 시작 index
  • 시작 5라면: 5 → 12 → 3 → 7 → 11 → 13 → 9 → 4 → 8 → 0 → 10 → 1 → 2 → 14 → 6 → 15 (정확히 15번 반복)
  • 합계 = 12+3+7+11+13+9+4+8+0+10+1+2+14+6+15 = 115 → x1 = 5, x2 = 115

7Phase 6 — 링크드 리스트 재배열

조건 1: 입력은 1~6의 순열

  • 각 x_i에 대해 x_i − 1 ≤ 5 (unsigned jbe) → 1 ≤ x_i ≤ 6
  • 이중 루프로 모든 쌍을 비교해 같은 값이 있으면 폭발 → 6개는 모두 다름 → 1~6이 정확히 한 번씩

조건 2: 입력이 고른 노드를 value 오름차순으로

  • 입력 x_i는 0x6042f0에서 시작하는 연결 리스트의 i번째 노드를 선택 (<+102>: x_i가 될 때까지 next를 따라감 — %rdx += 8이 아니라 8바이트 뒤에 저장된 주소를 읽는 것)
  • 선택한 노드 6개를 입력 순서대로 다시 연결 (<+155>~<+193>)
  • 인접 쌍 5개를 검사: 현재 노드 value ≤ 다음 노드 value 여야 함 (jle)
  • 즉 입력 정수 자체를 정렬하는 게 아니라, 각 숫자가 선택하는 노드의 value가 오름차순이 되는 순서를 찾는 문제

8분석 중 헷갈렸던 포인트 (수정 메모)

처음에 잘못 읽었다가 고친 것 — 시험에서도 같은 실수 조심

  • mov 0x30(%rsp,%rax,4), %eax → 주소 자체가 아니라 Memory[%rsp + 48 + 4×%rax]의 값을 읽음
  • cmp %eax, 0x0(%rbp) → %rbp는 입력값이 아니라 입력값의 주소 — 입력값끼리 비교하는 것
  • cmp $0x5, %ebx; jle → %ebx ≤ 5이면 점프. 점프 주소(0x401145)와 값을 비교하는 게 아님
  • mov 0x8(%rdx), %rdx → node.next (포인터). %rdx에 8을 더하는 게 아님
  • cmp %eax, (%rbx); jle → 현재 노드 value ≤ 다음 노드 value
