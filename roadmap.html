코딩 문제 로드맵 (중요도순 · Lec2~8 + LAB)

10/21 정리 · 위에서부터 체크하면서 풀면 됨 — 문제 자체는 문제 풀이 페이지에 정리돼 있음

사용법과 기준

  • 사용법: 위에서부터 체크하면서 풀기. 랩 문제는 허용 연산자·자료형·최대 연산 수를 지켜 직접 구현 → 테스트. 어셈블리 문제는 먼저 손으로 C 동작 복원 → GDB로 검증. 해설은 마지막에 확인
  • 중요도 기준: 현재 강의(Lec2~8)와 직접 연결되는가 > 실제 Data Lab/Bomb Lab 문제인가 > 시험형 CMU 15-213 기출인가 > 외부 자동채점으로 반복 가능한가. 출제 확률을 뜻하지 않음
  • 일치도 표기: 실습 원본 = 같은 수업 문제 · 직접 일치 = lab 문제 그 자체 · 기출 동일 개념 = 같은 개념을 묻는 다른 문제 · 자동 채점 = pwn.college·LeetCode 유사 연습. 시험·실습의 1:1 대체라고 가정하지 않기

S가장 먼저 — 핵심 18개

다른 것보다 우선. 01~06은 Data Lab의 핵심 비트/float 구현, 07~13은 GDB·Bomb, 14~18은 시험형 어셈블리·스택·실수·구조체 기출. 진도순이 아니라 시험·실습 연결성에 가중치를 준 순서.

  • 01addOK(x,y) — Lec2 · 직접 일치 · 부호비트/XOR로 signed overflow 판정. 동일 부호 + 결과 부호 역전 설명하기
  • 02logicalShift(x,n) — Lec2 · 직접 일치 · 산술/논리 시프트, n = 0·31 경계 처리. 허용 연산자 지키기
  • 03isLess(x,y) — Lec2 · 직접 일치 · x−y를 무작정 쓰지 않고 overflow를 피해 비교하기
  • 04float_twice(uf) — Lec3 · 직접 일치 · S/E/F 분리, 0·denorm·normal·∞·NaN 구분
  • 05float_f2i(uf) — Lec3 · 직접 일치 · 지수에 따른 shift와 음수/범위 초과/NaN 처리
  • 06float_i2f(x) — Lec3 · 직접 일치 · leading 1 탐색과 round-to-even. 어려워서 04~05 이후 추천
  • 07pwn.college Debugging Refresher — Lec4~6 · 실전 자동 채점 · Inspecting Registers → Examining Memory → Setting Breakpoints 3개부터. Bomb Lab 전에 권장
  • 08pwn.college Control Flow — Lec4~5 · 실전 자동 채점 · Comparing Values, Recognizing/Writing Loops 중심으로 cmp/test/jcc 익히기
  • 09bomb 랩 phase 1·2 — Lec5 · 실습 원본 · loop, cmp, 주소 증가 규칙을 disassembly로 복원
  • 10bomb 랩 phase 3 — Lec5 · 실습 원본 · 간접 점프와 case 매핑. LeetCode로는 직접 대체 불가
  • 11bomb 랩 phase 4 — Lec6 · 실습 원본 · call·ret·인자 전달·재귀 함수 동작 복원
  • 12bomb 랩 phase 5 — Lec5~7 · 실습 원본 · 배열을 따라가는 루프와 포인터 해석
  • 13bomb 랩 phase 6 — Lec6~7 · 실습 원본 · 구조체 포인터, 노드 재연결, 순서 조건 복원
  • 14CMU Fall 2012 P7 · Switch — Lec5 · 기출 동일 개념 · jump table → C switch 복원
  • 15CMU Fall 2012 P8 · Stack discipline — Lec6 · 기출 동일 개념 · call 반환 주소, saved registers, stack frame 계산
  • 16CMU Fall 2012 P5·P6 · Struct — Lec7 · 기출 동일 개념 · alignment/padding/필드 offset/lea 주소 계산
  • 17CMU Fall 2012 P3 · Floating point — Lec3 · 기출 동일 개념 · IEEE 754 인코딩/예외값/반올림을 손계산
  • 18CMU Fall 2012 P4 · Loops — Lec5 · 기출 동일 개념 · 어셈블리 분기/반복문을 C로 복원

A중요 보강 — 19~33

S를 대부분 끝냈다면 진행. LeetCode가 Data Lab 연산자 제한을 검사해 주지는 않음.

  • 19bitNor · absVal — Lec2 · 직접 일치 · De Morgan 및 sign mask. 01~03 막힐 때 앞서 해도 좋음
  • 20negate · float_abs — Lec2~3 · 직접 일치 · two's complement와 float sign bit/NaN
  • 21LeetCode 405 · Convert a Number to Hexadecimal — Lec2 · 개념 매우 유사 · 32비트 2의 보수로 음수의 16진수 표현
  • 22LeetCode 371 · Sum of Two Integers — Lec2 · 기술 유사 · XOR와 carry로 덧셈. Data Lab의 연산자 제약과는 다름
  • 23LeetCode 190 · Reverse Bits — Lec2 · 기술 유사 · mask/shift. 라이브러리 없이 32비트 직접 구현
  • 24LeetCode 201 · Bitwise AND of Numbers Range — Lec2 · 기술 유사 · 상위 공통 prefix와 AND의 의미를 설명
  • 25LeetCode 29 · Divide Two Integers — Lec2 · 관련 심화 · 시프트 기반 정수 나눗셈, TMin 및 0 방향 반올림
  • 26pwn.college Endian Escapades — Lec2·7 · 자동 채점 · Little-Endian Bytes, Cracking a Struct 중심
  • 27pwn.college The Stack, Revisited — Lec6·8 · 자동 채점 · caller frame, rsp, return address와 stack layout
  • 28pwn.college Assembly Assortment — Lec4~5 · 자동 채점 · Reverse the Calculation, Masking Bits, Shifting Left/Right, Loops on Data
  • 29CMU Fall 2011 P5 · Stack discipline — Lec6 · 기출 추가 · 재귀 호출과 stack 추적 심화
  • 30CMU Fall 2010 P3·P4·P5 · Arrays/Struct — Lec7 · 기출 추가 · 배열 스케일링, 구조체 정렬, 필드 접근
  • 31CMU Fall 2012 P2 · Integer encoding — Lec2 · 기출 추가 · signed/unsigned 변환, 2의 보수 및 확장
  • 32LeetCode 191 · Number of 1 Bits — Lec2 · 보조 기초 · bit counting, mask/shift. 위 문제들이 어렵다면 첫 문제로 이동 가능
  • 33LeetCode 231 · Power of Two — Lec2 · 보조 기초 · x & (x−1) 관찰. 범위가 좁아 우선도 낮음

5채점·운영 방식

  • Data Lab: btest/dlc로 검증. 기본 동작이 맞아도 연산 규칙을 어기면 완료 표시 X
  • Bomb Lab: 개인 바이너리와 GDB/objdump 사용. phase별 해답을 기록하는 것보다 cmp/test/jcc/call/ret/lea의 역할을 설명할 수 있어야 완료
  • CMU 기출: 파일 전체를 풀지 말고 지정한 P 번호만. 일부 과거 문제는 IA32 — x86-64 calling convention과 혼동하지 않기
  • pwn.college: Computing 101 기준. 옛 Assembly Crash Course는 아카이브라 새 Computing 101을 우선
  • LeetCode: C로 풀이 권장. 부호/자료형/오버플로 규칙을 명시하고 Python의 무제한 정수와 C의 32-bit 정수를 구분
