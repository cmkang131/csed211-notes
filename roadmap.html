코딩 문제 로드맵(Problem Roadmap) — 중요도순 · Lec2~8 + LAB

CSED211-컴퓨터 시스템 · 2026-10-21 정리 · 알고리즘 과목 코딩 로드맵과 동일한 중요도 번호·체크박스·원본 링크·유사도 표시 구성

📌

사용법 : 위에서부터 체크하면서 풀기. 랩 문제는 허용 연산자/자료형/최대 연산 수를 지켜 직접 구현 → 테스트. 어셈블리 문제는 먼저 손으로 C 동작 복원 → GDB로 검증. 해설은 마지막에 확인.

중요도 기준 : 현재 노션 강의(Lec2~8)와 직접 연결되는가 > 실제 Data Lab/Bomb Lab 문제인가 > 시험형 CMU 15-213 기출인가 > 외부 자동채점으로 반복 연습 가능한가. 출제 확률을 뜻하지 않음.

플랫폼/일치도 : 실습 원본=같은 수업 문제(수업 배포 파일로 실행), CMU 기출=같은 개념을 묻는 다른 문제, pwn.college=유사 실습 자동 채점, LeetCode=비트 연산 보조 자동 채점. *시험·실습의 1:1 대체라고 가정하지 않기.*

0. 가장 먼저 풀 순서 — 핵심 18개 (S)

다른 것보다 우선. 01~06은 Data Lab의 핵심 비트/float 구현, 07~13은 GDB·Bomb, 14~18은 시험형 어셈블리·스택·실수/구조체 기출. 이 순서는 진도순이 아니라 시험·실습 연결성에 가중치를 준 순서.

  • 01 · addOK(x,y) — Lec2 · 직접 일치 · 부호비트/XOR로 signed overflow 판정. 동일 부호+결과 부호 역전 설명하기.
  • 02 · logicalShift(x,n) — Lec2 · 직접 일치 · 산술/논리 시프트, n=0·31 경계 처리. 허용 연산자 지키기.
  • 03 · isLess(x,y) — Lec2 · 직접 일치 · x-y를 무작정 쓰지 않고 overflow를 피해 비교하기.
  • 04 · float_twice(uf) — Lec3 · 직접 일치 · S/E/F 분리, 0·denorm·normal·Infinity·NaN 구분.
  • 05 · float_f2i(uf) — Lec3 · 직접 일치 · 지수에 따른 shift와 음수/범위 초과/NaN 처리.
  • 06 · float_i2f(x) — Lec3 · 직접 일치 · leading 1 탐색과 round-to-even. 어려워서 04~05 이후 추천.
  • 07 · pwn.college Debugging Refresher — Lec4~6 · 실전 자동 채점 · Inspecting Registers → Examining Memory → Setting Breakpoints 3개부터. Bomb Lab 전에 권장.
  • 08 · pwn.college Control Flow — Lec4~5 · 실전 자동 채점 · Comparing Values, Recognizing/ Writing Loops 중심으로 cmp/test/jcc 익히기.
  • 09 · bomb 랩 — Lec5 · 실습 원본 · loop, cmp, 주소 증가 규칙을 disassembly로 복원.
  • 10 · bomb 랩 — Lec5 · 실습 원본 · 간접 점프와 case 매핑. LeetCode로는 직접 대체 불가.
  • 11 · bomb 랩 — Lec6 · 실습 원본 · call·ret·인자 전달·재귀 함수 동작 복원.
  • 12 · bomb 랩 — Lec5~7 · 실습 원본 · 배열을 따라가는 루프와 포인터 해석.
  • 13 · bomb 랩 — Lec6~7 · 실습 원본 · 구조체 포인터, 노드 재연결, 순서 조건 복원.
  • 14 · CMU Fall 2012 P7 · Switch — Lec5 · 기출 동일 개념 · jump table → C switch 복원. LeetCode보다 시험형 문제에 가까움.
  • 15 · CMU Fall 2012 P8 · Stack discipline — Lec6 · 기출 동일 개념 · call 반환 주소, saved registers, stack frame 계산.
  • 16 · CMU Fall 2012 P5·P6 · Struct — Lec7 · 기출 동일 개념 · alignment/padding/필드 offset/lea 주소 계산.
  • 17 · CMU Fall 2012 P3 · Floating point — Lec3 · 기출 동일 개념 · IEEE 754 인코딩/예외값/반올림을 손계산.
  • 18 · CMU Fall 2012 P4 · Loops — Lec5 · 기출 동일 개념 · 어셈블리 분기/반복문을 C로 복원.

    • 1. 중요 보강 — 19~33 (A)

    S를 대부분 끝냈다면 진행. 외부 온라인 저지로 비트 감각을 반복하고 부족한 시스템 개념을 실습한다. LeetCode가 Data Lab 연산자 제한을 검사해 주지는 않는다.

    • 19 · bitNorabsVal — Lec2 · 직접 일치 · De Morgan 및 sign mask. 01~03 막힐 때 앞서 해도 좋음.
    • 20 · negatefloat_abs — Lec2~3 · 직접 일치 · two's complement와 float sign bit/NaN.
    • 21 · LeetCode 405 · Convert a Number to Hexadecimal — Lec2 · 개념 매우 유사 · 32비트 2의 보수로 음수의 16진수 표현. 자동 채점.
    • 22 · LeetCode 371 · Sum of Two Integers — Lec2 · 기술 유사 · XOR와 carry로 덧셈. Data Lab의 연산자 제약과는 다름.
    • 23 · LeetCode 190 · Reverse Bits — Lec2 · 기술 유사 · mask/shift. 라이브러리 없이 32비트 직접 구현.
    • 24 · LeetCode 201 · Bitwise AND of Numbers Range — Lec2 · 기술 유사 · 상위 공통 prefix와 AND 의미를 설명.
    • 25 · LeetCode 29 · Divide Two Integers — Lec2 · 관련 심화 · 시프트 기반 정수 나눗셈, TMin 및 0 방향 반올림.
    • 26 · pwn.college Endian Escapades — Lec2·7 · 자동 채점 · Little-Endian Bytes, Cracking a Struct 중심.
    • 27 · pwn.college The Stack, Revisited — Lec6·8 · 자동 채점 · caller frame, rsp, return address와 stack layout.
    • 28 · pwn.college Assembly Assortment — Lec4~5 · 자동 채점 · Reverse the Calculation, Masking Bits, Shifting Left/Right, Loops on Data.
    • 29 · CMU Fall 2011 P5 · Stack discipline — Lec6 · 기출 추가 · 재귀 호출과 stack 추적 심화.
    • 30 · CMU Fall 2010 P3·P4·P5 · Arrays/Struct — Lec7 · 기출 추가 · 배열 스케일링, 구조체 정렬, 필드 접근.
    • 31 · CMU Fall 2012 P2 · Integer encoding — Lec2 · 기출 추가 · signed/unsigned 변환, 2의 보수 및 확장.
    • 32 · LeetCode 191 · Number of 1 Bits — Lec2 · 보조 기초 · bit counting, mask/shift. 위 문제들이 어렵다면 첫 문제로 이동 가능.
    • 33 · LeetCode 231 · Power of Two — Lec2 · 보조 기초 · x & (x-1) 관찰. 범위가 좁아 우선도 낮음.

      • 2. 확장/이후 진도 — 34~38 (B)

      Lecture 8의 버퍼 오버플로는 10/20 강의에 포함되지만, Attack Lab과 Cache Lab은 별도 실습이므로 해당 실습이 실제로 주어지면 우선순위를 다시 조정한다.

      • 34 · CS:APP Attack Lab (자가학습) — Lec8 확장 · buffer overflow, return address, code injection/ROP. 강의에서 Attack Lab 실습 시작할 때 순위를 올리기.
      • 35 · pwn.college Computer Memory — Lec7~8 · 메모리 접근 챌린지. 특정 모듈이 사이트에서 바뀌면 Computing 101 목차에서 선택.
      • 36 · CS:APP Cache Lab (자가학습) — 향후 memory hierarchy/cache 진도 이후. 현재 중간고사 최우선 문제와 혼합하지 않기.
      • 37 · CMU Fall 2012 P1 · Mixed warm-up — 기출 종합 점검 · 정수·어셈블리·스택·데이터 분야의 빈 개념 찾기.
      • 38 · C → x86-64 역컴파일 미니 실습 — 직접 실험/자동 채점 아님 · 짧은 C 함수 if, for, switch, 재귀, struct를 -O0과 -O2에서 비교.

        • 3. 오늘 바로 시작할 6문제

        5. 채점/운영 방식

        • Data Lab: 과목에서 제공한 btest/dlc가 있으면 그것으로 검증. 기본 동작이 맞아도 연산 규칙을 어기면 완료 표시 X.
        • Bomb Lab: 과목 개인 바이너리와 GDB/objdump 사용. Phase별 해답을 기록하는 것보다, cmp/test/jcc/call/ret/lea의 역할을 설명할 수 있어야 완료.
        • CMU 기출: F12 문제 PDF · 공식 해설. 파일 전체를 풀지 말고 지정한 P 번호만 풀이. 일부 과거 문제는 IA32이므로 x86-64와 calling convention을 혼동하지 않기.
        • pwn.college: Computing 101 전체 목록. 특정 challenge를 클릭한 뒤 풀이/flag로 완료 표시. 반대로 Assembly Crash Course 옛 과정은 아카이브라 새 Computing 101을 우선.
        • LeetCode: C로 풀이 권장. 부호/자료형/오버플로 규칙을 명시하고 Python의 무제한 정수와 C의 32-bit 정수를 구분.
