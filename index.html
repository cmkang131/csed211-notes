강의 노트

→
1강Course Overview
컴퓨터 시스템의 큰 그림: 하드웨어/소프트웨어 스택, 메모리 계층, 이 과목에서 배우는 것.
 →
2강Bits and Integers
비트 연산, 2의 보수, 부호 확장·절단, endian, 시프트, 덧셈 overflow. Data Lab 1의 직접 기반.
 →
3강Floating Point
IEEE 754 (S/E/F), normalized·denormalized·∞·NaN, round-to-even. Data Lab 2의 직접 기반.
 →
4강Machine-Level Programming I: Basics
x86-64 레지스터, mov와 주소 지정 방식, 산술 명령, lea, AT&T 문법 읽는 법.
 →
5강Machine-Level Programming II: Control
조건 코드, cmp/test, setX, 점프, 조건부 이동, 반복문 변환, switch와 jump table. 10/8 + 10/13 통합본.
 →
6강Machine-Level Programming III: Procedures
call/ret, 스택 프레임, 인자 전달, caller/callee-saved 레지스터, 재귀. Bomb Lab 재귀 phase 연계.
 →
7강Machine-Level Programming IV: Data
1차원·중첩 배열의 주소 계산, 구조체 정렬과 패딩, 포인터 산술. Bomb Lab phase 5·6 연계.
 →
8강Advanced Topics: Memory Layout & Buffer Overflow
메모리 배치, 버퍼 오버플로, 카나리, ROP. 공식 범위 안 (Lec2~8). 10/20 강의 분량.
 →
기말Memory Hierarchy · Cache · Virtual Memory
중간고사 범위 밖, 이후 진도 미리보기. 인터랙티브 4종: 메모리 계층 탐색기, 캐시 주소 해석기, 캐시 시뮬레이터, 가상 주소 변환.

실습 (LAB)

→
DLData Lab 정리
규칙과 제약, 자주 쓰는 비트 트릭, IEEE 비트 조작 패턴, 풀었던 함수들 복기. 시험의 실습 문제와 직결.
 →
BombBomb Lab 정리
phase별 어셈블리 읽기 전략, gdb 명령, 각 phase가 Lec4~7의 무엇을 묻는지.
슬라이드와 수업 녹취에서 직접 정리한 개인 노트. 출처가 불명확한 내용은 (추정) 표시. 모의고사 2탄은 문제 풀이 페이지의 모의고사 섹션에 수록.
