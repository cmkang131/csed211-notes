Q5 · 스택 프레임 계산

모의고사 2탄 · 자작 · Lec6 Procedures: 스택 프레임 구조와 16바이트 정렬 · 8점

문제 5

함수 foo가 call에 의해 진입한 직후 %rsp = 0xFF8이다. 프롤로그는 다음과 같다. 

foo:
    pushq %rbp
    pushq %rbx
    subq $24, %rsp
(a) return address, 저장된 %rbp, 저장된 %rbx의 주소와, 프롤로그 직후의 %rsp 값을 쓰시오. [4점]

(b) 프롤로그가 스택 포인터를 내린 총 바이트 수를 쓰시오. [2점]

(c) 프롤로그 직후 %rsp가 16바이트 정렬 조건을 만족하는지 계산으로 보이시오. [2점]

정답 보기
풀이
(a)
  1. call이 return address를 push → 0xFF8에 있음.
  2. pushq %rbp → %rsp = 0xFF0, %rbp는 0xFF0에 저장.
  3. pushq %rbx → %rsp = 0xFE8, %rbx는 0xFE8에 저장.
  4. subq $24 → %rsp = 0xFE8 − 24 = 0xFD0.
(b)
  1. 8 + 8 + 24 = 40바이트.
(c)
  1. 0xFD0 = 4048 = 16 × 253, 나머지 0 → 16바이트 정렬 만족. (call 직전 %rsp가 16 정렬이었다면 진입 직후는 ≡ 8 (mod 16); 여기서 40 ≡ 8 (mod 16)을 빼면 다시 16의 배수.)
최종 답ret@0xFF8, %rbp@0xFF0, %rbx@0xFE8, %rsp=0xFD0 · 40바이트 · 만족한다 (0xFD0 = 16 × 253)
