문제 16

8-bit 형식: 부호 1 / 지수 4 (bias = 7) / fraction 3. (a) 6.5 (b) 0 0000 011이 나타내는 값 (c) 가장 큰 유한 양수 (d) 가장 작은 양의 정규수 (e) 가장 작은 양의 비정규수 (f) +무한대.

같은 형식에서 1.5 = 1.100₂ × 2⁰이므로 부호 0, 지수 0111, fraction 100 → 0 0111 100.
힌트 보기
개념 정리
V = (−1)^s × M × 2^E. exp = 0이면 비정규(E = 1−bias, M = 0.f), exp = 전부 1이면 특수(∞/NaN), 아니면 정규(E = exp−bias, M = 1.f).
정답 보기

개념 정리는 위 힌트 보기에 있음

풀이
  1. (a) 6.5 = 110.1₂ = 1.101 × 2² → e = 2+7 = 9 = 1001, frac = 101 → 0 1001 101 (0x4D)
  2. (b) exp = 0000이라 비정규: E = 1−7 = −6, M = 3/8 → 3/8 × 2⁻⁶ = 3/512
  3. (c) 0 1110 111 = 1.875 × 2⁷ = 240
  4. (d) 0 0001 000 = 2⁻⁶
  5. (e) 0 0000 001 = 1/8 × 2⁻⁶ = 2⁻⁹
  6. (f) 0 1111 000
최종 답(a) 0 1001 101 (b) 3/512 (c) 240 (d) 2⁻⁶ (e) 2⁻⁹ (f) 0 1111 000
