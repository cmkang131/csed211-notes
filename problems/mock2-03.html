Q3 · switch와 점프 테이블

모의고사 2탄 · 자작 · Lec5 Control — jump table 복원 유형 · 8점

문제 3

다음 어셈블리를 보고 물음에 답하시오. 

f:
    cmpq $3, %rdi
    ja .L8
    jmp *.L4(,%rdi,8)
.L3:
    movl $10, %eax
    ret
.L5:
    movl $20, %eax
    addl $1, %eax
    ret
.L6:
    movl $30, %eax
    subl $5, %eax
    ret
.L7:
    movl $40, %eax
    ret
.L8:
    movl $-1, %eax
    ret
.L4:
    .quad .L3
    .quad .L5
    .quad .L6
    .quad .L7
(a) f의 C 코드를 switch 문을 사용해 복원하시오 (반환 타입 long, 인자 long x). [4점]

(b) 범위 검사에 jg 대신 ja를 쓰는 이유를 설명하시오. [2점]

(c) f(2)의 반환 값을 쓰시오. [2점]

정답 보기
풀이
(a)
  1. 테이블 .L4의 i번째 항목이 case i의 목적지.
  2. case 0 → 10, case 1 → 20+1 = 21, case 2 → 30−5 = 25, case 3 → 40, 그 외 → −1.
    long f(long x) {
    switch (x) {
        case 0: return 10;
        case 1: return 21;
        case 2: return 25;
        case 3: return 40;
        default: return -1;
    }
}
(b)
  1. 인덱스 x가 음수이면 unsigned 비교(ja)에서는 매우 큰 값으로 해석되어 default(.L8)로 빠진다. jg(부호 비교)였다면 음수 인덱스가 테이블 앞의 잘못된 주소를 참조하게 된다. ja 하나로 x > 3과 x < 0을 동시에 걸러낸다.
(c)
  1. case 2 → 30 − 5 = 25.
