Q6 · 재귀와 callee-saved 레지스터

모의고사 2탄 · 자작 · Lec6 Procedures — 재귀 번역 + 레지스터 저장 규약 · 10점

문제 6

다음 어셈블리를 보고 물음에 답하시오. 

fact:
    cmpq $1, %rdi
    jg .L2
    movl $1, %eax
    ret
.L2:
    pushq %rbx
    movq %rdi, %rbx
    leaq -1(%rdi), %rdi
    call fact
    imulq %rbx, %rax
    popq %rbx
    ret
(a) fact의 C 코드를 복원하시오 (long fact(long n)). [3점]

(b) %rbx를 push/pop하는 이유를 callee-saved 규약 관점에서 설명하시오. [3점]

(c) main이 fact(3)을 call한 시점부터 fact(1)이 실행되는 동안, 스택이 총 몇 바이트 내려가는지 내역과 함께 쓰시오. [4점]

정답 보기
풀이
(a)
  1. n ≤ 1이면 1 반환 (base case).
  2. 아니면 n을 %rbx에 보관, fact(n−1) 호출, 결과에 n을 곱함.
    long fact(long n) {
    if (n <= 1) return 1;
    return n * fact(n - 1);
}
(b)
  1. 재귀 호출 후에도 n이 필요한데 %rdi는 인자 레지스터(caller-saved)라 call 이후 값이 보장되지 않는다. 그래서 n을 callee-saved인 %rbx에 옮겨 보관한다. 대신 %rbx는 callee-saved이므로 사용 전 원래 값을 push로 저장하고 반환 전 pop으로 복원해 caller의 %rbx를 지켜야 한다.
(c)
  1. call fact(3)의 ret주소 8 + fact(3)의 pushq %rbx 8 + call fact(2)의 ret주소 8 + fact(2)의 pushq %rbx 8 + call fact(1)의 ret주소 8 = 40바이트. (fact(1)은 base case라 push 없음.)
최종 답n을 call 너머로 보존하려고 callee-saved %rbx를 쓰되, 규약상 원래 %rbx는 push/pop으로 보존 · 40바이트
