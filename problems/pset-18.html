18 · C의 float / double 성질: true/false?

Lec3 · 부동소수점 · 난이도 ★★

문제 18

다음 명제가 항상 참인지 판정하라.

  • (1) int x = 16777217 (2²⁴+1)에서 x == (int)(float)x
  • (2) (1e20 + -1e20) + 3.14 == 1e20 + (-1e20 + 3.14) (double)
  • (3) 0.1 + 0.2 == 0.3 (double)
  • (4) IEEE-754 binary32 환경에서, 이미 초기화된 유효한 float 값 f가 NaN이 아니라고 하자. 이때 f == -(-f)는 항상 참인가?
  • (5) (int)3.99와 (int)-3.99의 값
힌트 보기
float의 유효 숫자는 24비트. FP 덧셈은 결합법칙이 성립하지 않음. int 캐스트는 0 쪽으로 절단. 부호 반전은 부호 비트만 뒤집음.
정답 보기
풀이
  1. (1) false: float 유효 숫자 24비트라 2²⁴+1은 표현 불가, 2²⁴로 반올림
  2. (2) false: 왼쪽은 3.14, 오른쪽은 3.14가 −1e20에 흡수되어 0 → 결합법칙 불성립
  3. (3) false: IEEE-754 binary64에서 0.1과 0.2를 더한 결과는 0.3의 표현값과 다르다. 실제로 0.1 + 0.2는 0x1.3333333333334p-2, 0.3은 0x1.3333333333333p-2로 표현되므로 비교 결과는 false이다.
  4. (4) true: f가 이미 초기화되어 있고 NaN이 아니라면, 부호 반전을 두 번 적용하면 원래 값으로 돌아온다. 이 성질은 +0, −0, +∞, −∞에도 성립한다.
  5. (5) 3과 −3 (0 쪽으로 절단)
최종 답(1) false (2) false (3) false (4) true (5) 3, −3
