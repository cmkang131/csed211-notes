18 · C의 float / double 성질: true/false?

Lec3 · 부동소수점 · 난이도 ★★

문제 18

(1) int x = 16777217 (2²⁴+1)에서 x == (int)(float)x (2) (1e20 + -1e20) + 3.14 == 1e20 + (-1e20 + 3.14) (double) (3) 0.1 + 0.2 == 0.3 (double) (4) float f; f == -(-f)는 NaN이 아닐 때 항상 true? (5) (int)3.99와 (int)-3.99의 값.

(int)2.9는 2, (int)-2.9는 -2 · 0.5+0.25 == 0.75는 이진 부동소수점에서 참.
힌트 보기
float의 유효 숫자는 24비트. FP 덧셈은 결합법칙이 성립하지 않음. int 캐스트는 0 쪽으로 절단. 부호 반전은 부호 비트만 뒤집음.
정답 보기
풀이
  1. (1) false: float 유효 숫자 24비트라 2²⁴+1은 표현 불가, 2²⁴로 반올림
  2. (2) false: 왼쪽은 3.14, 오른쪽은 3.14가 −1e20에 흡수되어 0 → 결합법칙 불성립
  3. (3) false: 이진수로 정확히 표현 불가
  4. (4) true: 부호 비트만 두 번 뒤집음
  5. (5) 3과 −3 (0 쪽으로 절단)
최종 답(1) false (2) false (3) false (4) true (5) 3, −3
