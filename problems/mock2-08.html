Q8 · 2차원 배열 주소 계산

모의고사 2탄 · 자작 · Lec7 Data — 다차원 배열 인덱싱과 주소식 · 8점

문제 8

int A[3][4]의 시작 주소는 0x1000이고, i는 %rsi, j는 %rdx, A는 %rdi에 있다. 

movq %rsi, %rax
salq $4, %rax
leaq (%rax,%rdx,4), %rax
movl (%rdi,%rax), %eax
(a) 이 코드가 계산하는 C 식과, &A[i][j]의 일반식을 쓰시오. [3점]

(b) A[2][3]의 주소를 16진수로 쓰시오. [3점]

(c) 배열 A 전체의 크기(바이트)를 쓰시오. [2점]

정답 보기
풀이
(a)
  1. salq $4로 %rax = 16·i, leaq로 %rax = 16·i + 4·j, movl로 해당 주소의 int를 읽는다. 행 하나는 int 4개 = 16바이트이므로 &A[i][j] = A + 16·i + 4·j = A + 4·(4i + j).
(b)
  1. 0x1000 + 16·2 + 4·3 = 0x1000 + 44 = 0x102C.
(c)
  1. 3 × 4 × 4바이트 = 48바이트.
최종 답A[i][j], &A[i][j] = A + 16i + 4j · 0x102C · 48바이트
