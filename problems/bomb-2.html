Bomb Lab Phase 2 — 2배씩 커지는 수열

Bomb Lab · gdb disassembly 분석

Phase 2

다음은 phase_2의 disassembly다. 폭탄을 해제하는 입력 6개를 찾아라.

  callq read_six_numbers        # 정수 6개를 스택에 저장
  cmpl $0x1, (%rsp)             # x1 = 1이어야 함
  je   <phase_2+52>
  ...
  mov  -0x4(%rbx), %eax         # %eax = 이전 원소
  add  %eax, %eax               # %eax = 2 × 이전 원소
  cmp  %eax, (%rbx)             # 현재 원소와 비교
  je   <phase_2+41>            # x_i = 2 × x_(i-1) 여야 함
  add  $0x4, %rbx               # 다음 정수로
  cmp  %rbp, %rbx
  jne  <phase_2+27>            # 끝까지 반복
힌트 보기
read_six_numbers는 정수 6개를 스택에 연속 저장한다. 첫 원소 조건과 "현재 원소 = f(이전 원소)" 관계를 루프에서 읽는다.

풀이
  1. loop 구조: %rbx가 두 번째 정수부터 마지막까지 돌면서 "현재 = 2 × 이전"을 검사
  2. x1 = 1이고 2배씩 → 1, 2, 4, 8, 16, 32
