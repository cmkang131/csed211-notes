01 · while 루프 (jump-to-middle)

Lec4·5 · 제어 흐름 | Bomb Lab 연계 · 난이도 ★★

문제 01 
f:  movl $0, %eax
    movl $0, %edx
    jmp .L2
.L3: addl %edx, %eax
    addl $1, %edx
.L2: cmpl %edi, %edx
    jl .L3
    ret

int f(int n)의 C 코드를 복원하고, f(5)와 f(-3)의 값을 구하라.

힌트 보기
f(4) = 0+1+2+3 = 6, f(0) = 0 (반복문이 실행되지 않음). 몸통 블록(.L3) 뒤에 조건 검사(.L2)가 오고, 처음엔 jmp로 조건부터 뛰는 구조는 while 루프의 컴파일 결과(jump-to-middle). cmpl %edi, %edx는 %edx − %edi이고, jl은 signed로 %edx < %edi일 때 점프.
정답 보기
풀이
  1. %eax = 0, %edx = 0 — 반환값과 counter 초기화
  2. jmp .L2 — 루프 진입 전 조건부터 검사하러 이동 (while 구조의 특징)
  3. .L2에서 %edx < %edi이면 .L3(몸통)으로 점프 — 조건은 i < n
  4. .L3: %eax += %edx, %edx += 1 → sum += i; i++
최종 답int f(int n){ int sum = 0; for (int i = 0; i < n; i++) sum += i; return sum; } · f(5) = 0+1+2+3+4 = 10, f(-3) = 0 (처음부터 i < n이 거짓)
