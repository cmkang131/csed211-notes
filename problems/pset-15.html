문제 15

long f(long a, int b, char *c, long d, long e, long g, long h). 각 인자는 어디에? 반환값은?

long add(long a, int b)라면 첫 인자 a는 %rdi, 둘째 b는 %esi로 전달되고 결과는 %rax로 반환.
힌트 보기
정수·포인터 인자는 %rdi → %rsi → %rdx → %rcx → %r8 → %r9 순서, 7번째부터는 stack. 반환값은 %rax. int 인자는 32-bit register(%esi 꼴)로 전달.
정답 보기
풀이
  1. 앞 6개를 register에 순서대로: a = %rdi, b = %esi (int라 32-bit), c = %rdx, d = %rcx, e = %r8, g = %r9
  2. 7번째 h는 stack: 함수 진입 시점 8(%rsp) (0(%rsp)는 return address)
최종 답a %rdi · b %esi · c %rdx · d %rcx · e %r8 · g %r9 · h 스택 8(%rsp) · 반환값 %rax
