문제 02 
struct node { long val; struct node *next; int arr[4]; };

g:  movq 8(%rdi), %rax
    movl 16(%rax,%rsi,4), %eax
    ret
h:  leaq 16(%rdi,%rsi,4), %rax
    ret

(%rdi = struct node *p, %rsi = long i). g와 h의 C 코드는?

현재 node의 arr = {1,2,3,4}, 다음 node의 arr = {10,20,30,40}, i = 2라면 각 배열의 원소 값은 3과 30. g는 값을, h는 특정 원소의 주소를 돌려준다는 차이를 확인.
힌트 보기
struct field offset은 선언 순서대로 쌓임: long 0, pointer 8, int[4] 16. movq D(%rdi)는 메모리를 읽지만 leaq는 주소 계산만 하고 메모리를 읽지 않음.
정답 보기
풀이
  1. offset 확정: val = 0, next = 8, arr = 16 (선언 순서, 8바이트 정렬)
  2. g 첫 명령: 8(%rdi) → p->next를 읽음. 둘째 명령: 16(%rax,%rsi,4) → next->arr[i]를 읽음
  3. h는 leaq 한 번: 메모리 읽기 없이 &p->arr[i] 주소만 계산
최종 답int g(struct node *p, long i){ return p->next->arr[i]; } · int *h(struct node *p, long i){ return &p->arr[i]; }
