Bomb Lab Phase 6: 링크드 리스트 재배열

Bomb Lab · gdb disassembly 분석

Phase 6

Phase 6는 1~6의 순열을 입력받는다 (범위·중복 검사). 재배열된 리스트가 value 오름차순이 되도록 하는 입력을 찾아라.

  1. 입력 x_i는 0x6042f0에서 시작하는 연결 리스트의 i번째 노드를 선택한다
  2. 선택한 노드 6개를 입력 순서대로 다시 연결한다

힌트 보기
링크드 리스트: 노드 주소·값·next 포인터를 표로 정리하고, 재배열 결과가 만족해야 할 순서 조건(오름차순)을 읽는다. 다음 노드는 포인터를 읽어 이동 (주소 +8이 아님).
정답 보기
풀이
  1. 각 x_i에 대해 x_i − 1 ≤ 5 (unsigned jbe) → 1 ≤ x_i ≤ 6
  2. 이중 루프로 모든 쌍을 비교해 같은 값이 있으면 폭발 → 6개는 모두 다름 → 1~6이 정확히 한 번씩
  3. 입력 x_i는 0x6042f0에서 시작하는 연결 리스트의 i번째 노드를 선택 (<+102>: x_i가 될 때까지 next를 따라감: %rdx += 8이 아니라 8바이트 뒤에 저장된 주소를 읽는 것)
  4. 선택한 노드 6개를 입력 순서대로 다시 연결 (<+155>~<+193>)
  5. 인접 쌍 5개를 검사: 현재 노드 value ≤ 다음 노드 value 여야 함 (jle)
  6. 즉 입력 정수 자체를 정렬하는 게 아니라, 각 숫자가 선택하는 노드의 value가 오름차순이 되는 순서를 찾는 문제
