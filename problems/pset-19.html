19 · Pointer 연산

Lec7 · 데이터 · 난이도 ★

문제 19

int *p = (int *)0x1000; char *q = (char *)0x1000; long *r = (long *)0x1000. p+3, q+3, r+3의 값은? 그리고 *(p+2)와 같은 배열 표기는?

다음은 실제 C 프로그램의 정수-포인터 변환이나 메모리 배치의 유효성을 검증하는 문제가 아니라, Linux x86-64, LP64의 일반적인 주소 모델에서 포인터 산술의 바이트 오프셋을 계산하는 문제다. 각 포인터 계산은 독립된 가상 사례로 취급한다. 해당 포인터가 주어진 시작 주소에 있는, 해당 자료형의 원소를 충분히 포함하는 배열을 가리킨다고 가정한다.
int *a = (int *)0x2000; char *b = (char *)0x2000;이면 a+2 = 0x2008, b+2 = 0x2002: 포인터에 더할 때 자료형에 따라 이동 바이트 수가 다름.
힌트 보기
자료형이 T인 포인터 T *x에 대해 x+n은 배열의 원소를 n개 이동한 포인터다. 이 문제의 주소 모델에서 바이트 오프셋은 n×sizeof(T)이다. 배열 인덱싱은 x[i]와 *(x+i)가 동등하다. 단, 실제 C 프로그램에서는 포인터 산술과 역참조가 유효한 객체 및 배열 범위 안에서 이루어져야 한다.
정답 보기
풀이
  1. p+3 = 0x1000 + 3×4 = 0x100C
  2. q+3 = 0x1000 + 3×1 = 0x1003
  3. r+3 = 0x1000 + 3×8 = 0x1018
최종 답p+3 = 0x100C · q+3 = 0x1003 · r+3 = 0x1018 · *(p+2) = p[2]
