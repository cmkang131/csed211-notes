Lec7 · 데이터 · 난이도 ★

문제 19

int *p = (int *)0x1000; char *q = (char *)0x1000; long *r = (long *)0x1000. p+3, q+3, r+3의 값은? 그리고 *(p+2)와 같은 배열 표기는?

int *a = (int *)0x2000; char *b = (char *)0x2000;이면 a+2 = 0x2008, b+2 = 0x2002 — 포인터에 더할 때 자료형에 따라 이동 바이트 수가 다름.
힌트 보기
포인터 + n은 n × sizeof(타입) 바이트 이동. p[i] ≡ *(p+i).
정답 보기
풀이
  1. p+3 = 0x1000 + 3×4 = 0x100C
  2. q+3 = 0x1000 + 3×1 = 0x1003
  3. r+3 = 0x1000 + 3×8 = 0x1018
최종 답p+3 = 0x100C · q+3 = 0x1003 · r+3 = 0x1018 · *(p+2) = p[2]
