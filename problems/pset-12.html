12 · 반올림 (round-to-even)

Lec3 · 부동소수점 | Data Lab 연계 · 난이도 ★★

문제 12

1.0625 (= 17/16)와 1.1875 (= 19/16)를 같은 형식(8-bit, 부호 1 / 지수 4, bias 7 / fraction 3)으로 인코딩하라.

같은 형식에서 1.125 = 1.001₂는 3비트 fraction에 정확히 들어가므로 0 0111 001.
힌트 보기
개념 정리
fraction에 안 들어가는 나머지 비트가 정확히 절반(tie)이면, 올림/버림 중 마지막 비트가 짝수가 되는 쪽을 선택 (round-to-even).
정답 보기

개념 정리는 위 힌트 보기에 있음

풀이
  1. 1.0625 = 1.0001₂ — 3비트 뒤에 남는 "1"은 정확히 중간(tie) → 짝수 쪽(마지막 비트 0)인 1.000 선택 → 0 0111 000
  2. 1.1875 = 1.0011₂ — 1.001|1은 tie. 1.001은 홀수 → 올림 → 1.010 = 1.25 → 0 0111 010
최종 답1.0625 → 0 0111 000 · 1.1875 → 0 0111 010
