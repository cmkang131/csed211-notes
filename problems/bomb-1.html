Bomb Lab Phase 1 — 문자열 비교

Bomb Lab · gdb disassembly 분석

Phase 1

다음은 phase_1의 disassembly다. 폭탄을 해제하는 입력을 찾아라.

phase_1:
  sub  $0x8, %rsp
  mov  $0x4024c0, %esi      # 비교할 문자열 주소를 %esi에
  callq strings_not_equal   # %eax = 같으면 0, 다르면 1
  test %eax, %eax           # %eax = 0이면 ZF=1
  je   0x400f07             # ZF=1이면 폭발 건너뜀
  callq explode_bomb
힌트 보기
strings_not_equal은 두 문자열이 같으면 %eax = 0. 비교 대상 문자열의 주소는 mov $ADDR, %esi로 싣는다. gdb의 x/s ADDR로 메모리 속 문자열을 그대로 읽을 수 있다.
