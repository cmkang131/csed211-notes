문제 11

int conditional(int x, int y, int z) — 즉 x ? y : z — 를 다음 제약으로 구현하시오. · 허용 연산자: ! ~ & ^ | + << >> · 상수는 0~255(0xFF)만 사용 가능 · if, ?:, 반복문, 매크로, 함수 호출 금지 · 최대 8 ops (a) 구현을 C 코드로 쓰시오. [6점]

(b) x=0, y=10, z=20일 때와 x=5, y=10, z=20일 때, 마스크 m의 값과 반환 값을 각각 보이며 왜 맞는지 설명하시오. [4점]

정답 보기
풀이
(a)
  1. !!x로 x를 0 또는 1로 정규화.
  2. << 31 >> 31 (arithmetic shift)로 1을 all-1 마스크 0xFFFFFFFF로 확장. x=0이면 마스크는 0.
  3. (m & y) | (~m & z): m이 all-1이면 y, all-0이면 z.
    int conditional(int x, int y, int z) {
    int m = (!!x) << 31 >> 31;
    return (m & y) | (~m & z);
}
    사용 연산 7개(!, !, <<, >>, &, ~, |)로 제한(8) 이내.
(b)
  1. x=0: !!x = 0 → m = 0 → (0 & 10) | (~0 & 20) = 0 | (0xFFFFFFFF & 20) = 20 = z ✓.
    x=5: !!x = 1 → m = 1<<31 = 0x80000000, arithmetic >> 31 → 0xFFFFFFFF → (0xFFFFFFFF & 10) | (0 & 20) = 10 = y ✓.
    마스크가 all-1이면 y를, all-0이면 z를 그대로 통과시키는 구조.
최종 답x=0 → m=0, 반환 20 / x=5 → m=0xFFFFFFFF, 반환 10
