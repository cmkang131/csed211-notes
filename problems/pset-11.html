11 · 덧셈 Overflow 검출

Lec2 · 비트 연산 | Data Lab 연계 · 난이도 ★★★

문제 11

int 두 개 x, y의 합이 오버플로 없이 표현되면 1, 아니면 0을 반환하는 함수를 연산자 제한 없이 작성하라.

(32-bit int 가정) x = 10, y = 20 → 합 30은 표현 가능 → 1 · x = INT_MAX, y = 1 → 오버플로 → 0. 일반 C에서 signed overflow 자체는 정의되지 않음.
힌트 보기
오버플로는 x와 y의 부호가 같고 합의 부호가 다를 때만 발생. 부호 비트는 ^와 >> 31로 추출.
정답 보기
풀이
  1. x, y를 uint32_t로 변환한다. 변환은 2^32를 법으로 한 비트 패턴에 대응한다.
  2. s = ux + uy를 계산한다. unsigned 덧셈은 2^32를 법으로 정의되므로 signed overflow가 발생하지 않는다.
  3. ux ^ s의 최상위 비트는 x와 합의 부호 비트가 다를 때 1이다. uy ^ s도 같은 방식으로 해석한다.
  4. ((ux ^ s) & (uy ^ s)) >> 31은 오버플로가 발생할 때만 1이 된다. 따라서 !overflow는 오버플로가 없으면 1, 있으면 0을 반환한다.
최종 답#include <stdint.h>
int add_fits(int x, int y) {
  uint32_t ux = (uint32_t)x;
  uint32_t uy = (uint32_t)y;
  uint32_t s = ux + uy;
  uint32_t overflow = ((ux ^ s) & (uy ^ s)) >> 31;
  return !overflow;
}
