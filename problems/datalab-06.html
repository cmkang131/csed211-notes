Data Lab 연습 06

Data Lab · bitwise 연산 제한

문제 6

logicalShift(0x80000000, 31)의 mask와 결과를 구하라.

힌트 보기
logical shift = arithmetic >> 후 채워진 상위 1들을 mask로 지우기. 상위 n bit만 0이고 나머지가 1인 mask를 만들어 &한다.
정답 보기
풀이
  1. (1 << 31) >> 31 = 0xFFFFFFFF → << 1 = 0xFFFFFFFE → mask = ~ = 0x00000001
  2. 1 << 31은 Data Lab의 32-bit 비트벡터 모델 기준 — 일반 ISO C에서는 signed int의 최상위 비트 시프트가 UB일 수 있음
  3. x >> 31 = 0xFFFFFFFF → 결과 = 0xFFFFFFFF & 0x00000001 = 1
최종 답mask = 0x00000001, 결과 1
