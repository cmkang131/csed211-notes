Bomb Lab Phase 4 — 재귀 함수 func4

Bomb Lab · gdb disassembly 분석

Phase 4

다음은 phase_4의 disassembly다. func4를 C로 복원하고 폭탄을 해제하는 입력 2개를 찾아라.

  cmpl $0x2,%eax          # sscanf로 정확히 2개
  mov 0xc(%rsp),%eax
  sub $0x2,%eax
  cmp $0x2,%eax           # 0 ≤ x2−2 ≤ 2 → 2 ≤ x2 ≤ 4 (unsigned jbe)
  jbe <phase_4+51>
  ...
  mov 0xc(%rsp),%esi      # 두 번째 인자 = x2
  mov $0x5,%edi           # 첫 번째 인자 = 5
  callq func4
  cmp 0x8(%rsp),%eax      # x1 = func4(5, x2) 여야 함
힌트 보기
재귀 함수는 반환 규칙을 C로 복원한 뒤, 원하는 반환 값이 나오는 입력을 역산한다. 종료 조건(base case)부터 확인.
정답 보기
풀이
  1. func4(5, x2) = 12·x2 이고 x1 = 12·x2 여야 함. 2 ≤ x2 ≤ 4 중 x2 = 2 → x1 = 24
func4(n = %edi, x = %esi):
  if (n <= 0) return 0
  if (n == 1) return x
  a = func4(n-1, x)
  b = func4(n-2, x)
  return a + x + b
