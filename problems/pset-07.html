07 · struct Alignment(정렬) (x86-64)

Lec7 · 데이터 · 난이도 ★★

문제 07 
struct S { char a; int b; short c; char d; long e; char f[3]; };

(a) 각 field의 offset과 sizeof(S) (b) sizeof를 가장 작게 만드는 field 순서와 그 크기.

struct T { char a; int b; char c; };라면 offset은 a:0, b:4, c:8, sizeof(T) = 12 (일반적인 x86-64 정렬).
힌트 보기
각 field offset은 자기 alignment의 배수로 올림하고, 전체 크기는 최대 alignment의 배수. 선언 순서를 바꾸면 padding이 달라짐 — 큰 타입부터 배치하면 padding이 줄어듦.
정답 보기
풀이
  1. (a) a:0 (char 1B) → b는 4의 배수 필요 → 4 → c는 2의 배수 → 8 → d:10 → e는 8의 배수 → 16 → f:24–26
  2. 끝이 27인데 전체 정렬이 max 8 → 8의 배수로 올림 → sizeof(S) = 32
  3. (b) 큰 것부터 e, b, c, a, d, f → offset 0, 8, 12, 14, 15, 16–18 → 끝 19 → 8의 배수 올림 → 24
최종 답(a) a:0 b:4 c:8 d:10 e:16 f:24, sizeof = 32 (b) e, b, c, a, d, f 순서로 24
