Bomb Lab Phase 5 — 배열을 따라가는 루프

Bomb Lab · gdb disassembly 분석

Phase 5

다음은 phase_5의 disassembly다. 폭탄을 해제하는 입력을 찾아라.

  mov 0xc(%rsp),%eax
  and $0xf,%eax           # x1의 마지막 4 bit만 남김
  cmp $0xf,%eax
  je  explode_bomb        # 1111이면 안 됨
  mov $0x0,%ecx           # %ecx = 합계
  mov $0x0,%edx           # %edx = 반복 횟수
loop:
  add $0x1,%edx
  cltq
  mov 0x402580(,%rax,4),%eax   # %eax = arr[%rax]
  add %eax,%ecx                # 합계에 더함
  cmp $0xf,%eax
  jne loop                     # arr 값이 15가 되면 종료
  cmp $0xf,%edx
  jne explode_bomb             # 반복 횟수 = 15여야 함
  cmp 0x8(%rsp),%ecx           # 합계 = x2 여야 함
  je  <phase_5+104>

배열 chasing: 현재 값을 다음 인덱스로 쓰는 루프. 배열 내용은 gdb x/16dw로 읽고, 루프 횟수·합계 조건을 같이 본다.

풀이
  1. arr[i]를 다음 index로 삼아 값이 15일 때까지 따라가는 포인터 체이스 — 입력 x1의 하위 4 bit가 시작 index
  2. 시작 5라면: 5 → 12 → 3 → 7 → 11 → 13 → 9 → 4 → 8 → 0 → 10 → 1 → 2 → 14 → 6 → 15 (정확히 15번 반복)
  3. 합계 = 12+3+7+11+13+9+4+8+0+10+1+2+14+6+15 = 115 → x1 = 5, x2 = 115
