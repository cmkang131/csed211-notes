Lec2 · 비트·정수 | Data Lab 연계 · 난이도 ★

문제 20

x = 0xB4 (8-bit). (a) signed 값 (b) unsigned 값 (c) x >> 2 산술 시프트 결과(16진수와 10진수) (d) 논리 시프트 결과 (e) −x.

0xF0 = 11110000₂는 unsigned로 240, signed로 −16 · 산술 오른쪽 2비트 시프트는 0xFC(−4), 논리 시프트는 0x3C(60).
힌트 보기
개념 정리
signed 해석은 최상위 비트에 −128의 가중치. 산술 시프트는 부호 비트를 복사, 논리 시프트는 0을 채움. −x = ~x + 1.
정답 보기

개념 정리는 위 힌트 보기에 있음

풀이
  1. 0xB4 = 10110100₂
  2. (a) −128+32+16+4 = −76 (b) 180
  3. (c) 산술: 부호 1 복사 → 11101101 = 0xED = −19
  4. (d) 논리: 0 채움 → 00101101 = 0x2D = 45
  5. (e) ~x+1 = 01001100 = 0x4C = 76
최종 답(a) −76 (b) 180 (c) 0xED = −19 (d) 0x2D = 45 (e) 0x4C = 76
