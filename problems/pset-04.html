문제 04

다음을 Data Lab 제약대로 구현하라.

  • (a) bitXor(x, y): ~와 &만 사용
  • (b) conditional(x, y, z): x ? y : z (! ~ & ^ | + << >> 허용)
  • (c) 부호 있는 int x를 8로 나눈 값(0 쪽으로 반올림)을 / 없이
  • (d) x × 15를 시프트와 덧셈·뺄셈으로
힌트 보기
De Morgan: x|y = ~(~x & ~y) · 모든 비트가 0이거나 1인 마스크: (!!x << 31) >> 31 · 음수 나눗셈은 bias를 더해야 0 쪽으로 반올림 · ×(2^k − 1) = (x<<k) − x.
정답 보기
풀이
  1. (a) XOR = (x|y)에서 겹치는 비트를 뺀 것. |는 De Morgan으로 만들기: return ~(~x & ~y) & ~(x & y);
  2. (b) x가 참이면 mask = −1(전부 1), 거짓이면 0이 되게 하고 mask로 y·z 선택: int mask = (!!x << 31) >> 31; return (mask & y) | (~mask & z);
  3. (c) 음수일 때만 bias 2³−1 = 7을 더해야 0 쪽으로 반올림됨: (x>>31)&7이 그 bias: return (x + ((x >> 31) & 7)) >> 3;
  4. (d) 15 = 16 − 1 → (x << 4) - x (즉 (x<<4) + ~x + 1)
최종 답(a) ~(~x & ~y) & ~(x & y) (b) (!!x<<31)>>31 마스크로 선택 (c) (x + ((x>>31) & 7)) >> 3 (d) (x<<4) − x
