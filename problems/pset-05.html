문제 05

unsigned uf를 float 비트 패턴으로 보고 2×f의 비트 패턴을 반환하라. NaN이면 인자를 그대로 반환.

uf = 0x3F800000 (1.0f) → 0x40000000 (2.0f) · uf = 0x00000000 (+0.0f) → 그대로 · uf = 0x7FC00000 (NaN) → 그대로.
힌트 보기
float = sign(1) + exp(8) + frac(23). exp == 0이면 비정규, exp == 0xFF면 특수(∞/NaN), 그 외 정규. 정규수에서 지수 +1 = 값 ×2. 비정규는 fraction을 한 칸 shift하면 됨.
정답 보기
풀이
  1. 부호·지수·fraction을 분해: s = uf & 0x80000000, e = (uf>>23) & 0xFF, f = uf & 0x7FFFFF
  2. e == 0xFF (inf·NaN) → 그대로 반환 (NaN 조건 + inf는 2배해도 inf)
  3. e == 0 (비정규) → fraction을 shift: s | (f<<1) — 넘치는 비트가 지수로 올라가 자연스럽게 정규수로 전환
  4. e == 0xFE → 2배하면 지수가 0xFF가 되어 ∞: s | 0x7F800000
  5. 나머지 정규수 → 지수 +1: uf + 0x00800000
unsigned s = uf & 0x80000000, e = (uf >> 23) & 0xFF, f = uf & 0x7FFFFF;
if (e == 0xFF) return uf;             // inf 또는 NaN
if (e == 0)    return s | (f << 1);   // 비정규: fraction shift
if (e == 0xFE) return s | 0x7F800000; // 2배하면 무한대
return uf + 0x00800000;               // 지수 +1
최종 답0x3F800000(1.0f) → 0x40000000(2.0f) · NaN·inf·±0은 그대로 · 비정규는 fraction shift
