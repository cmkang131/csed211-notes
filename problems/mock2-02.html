Q2 · 루프 어셈블리 → C 복원

모의고사 2탄 · 자작 · Lec5 Control: do-while 번역 유형 (강의 루프 번역 규칙 기반) · 8점

문제 2

다음 어셈블리를 보고 물음에 답하시오. 

f:
    movl $1, %eax
.L2:
    imull %edi, %eax
    subl $1, %edi
    jne .L2
    ret
(a) f의 C 코드를 복원하시오. 함수 시그니처는 int f(int n)이다. [4점]

(b) f(4)와 f(5)의 값을 쓰시오. [2점]

(c) f(0)을 호출하면 어떻게 되는지 반환 값과 반복 횟수 관점에서 설명하시오. [2점]

정답 보기
풀이
(a)
  1. 진입 즉시 %eax=1로 두고 본문을 먼저 실행한 뒤 조건을 검사 → do-while 구조.
  2. 본문: result *= n; n = n − 1.
  3. subl이 세팅한 ZF로 n != 0이면 반복.
    int f(int n) {
    int result = 1;
    do {
        result *= n;
        n = n - 1;
    } while (n != 0);
    return result;
}
(b)
  1. f(4) = 4·3·2·1 = 24. f(5) = 5·4·3·2·1 = 120.
(c)
  1. do-while이라 본문이 먼저 1회 실행되어 result = 0. 이후 n은 −1, −2, … 로 감소하다가 32비트에서 2^32회 감소 후 다시 0이 되면 종료. 무한 루프는 아니지만 사실상 멈춘 것처럼 보인다. 반환 값은 0.
최종 답f(4)=24, f(5)=120 · 0 반환 (약 2^32회 반복 후 종료)
