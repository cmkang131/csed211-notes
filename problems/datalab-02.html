문제 2

8-bit 값 b = 11010110에 대해 b << 2, logical b >> 3, arithmetic b >> 3을 구하라.

힌트 보기
<<는 항상 오른쪽을 0으로 채우는 shift. >>는 두 종류: logical은 왼쪽을 0으로, arithmetic은 부호 bit(MSB)로 채운다. signed int의 >>는 arithmetic.
정답 보기
풀이
  1. b << 2 = 01011000 (위 2 bit 소실, 아래 0 채움)
  2. logical >> 3 = 00011010 (왼쪽 0 채움)
  3. arithmetic >> 3 = 11111010 (MSB 1 → 왼쪽 세 칸을 1로)
최종 답01011000 · 00011010 · 11111010
