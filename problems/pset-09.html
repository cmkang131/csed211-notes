문제 09

int A[5][3], A의 시작 주소 0x1000. &A[3][2]의 주소는? 그리고 아래 asm은 어떤 함수인가 (M은 열 수).

get: leaq (%rsi,%rsi,2), %rax
     leaq (%rdi,%rax,4), %rax
     movl (%rax,%rdx,4), %eax
     ret
int B[2][4]의 시작 주소가 0x1000이라면 &B[1][2] = 0x1000 + (1×4+2)×4 = 0x1018. 원문 배열은 행 길이가 다름.
힌트 보기
row-major: 주소 = base + (i × 열 수 + j) × sizeof(원소). leaq (%rsi,%rsi,2) = 3×%rsi 꼴의 스케일 패턴을 열 수로 읽기.
정답 보기
풀이
  1. &A[3][2] = 0x1000 + 4×(3×3 + 2) = 0x1000 + 44 = 0x102C
  2. asm 해석: %rax = 3i → %rax = A + 12i (행 하나가 3×4 = 12B) → 값 = *(A + 12i + 4j)
최종 답0x102C · int get(int A[][3], long i, long j){ return A[i][j]; } (i = %rsi, j = %rdx)
