06 · Switch / Jump table (bomb lab phase 3 유형)

Lec5 · 제어 흐름 | Bomb Lab 연계 · 난이도 ★★★

문제 06 
f:    subq $10, %rdi
      cmpq $5, %rdi
      ja .Ldef
      jmp *.Ltab(,%rdi,8)
.LA:  leaq 0(,%rsi,8), %rax
      ret
.LB:  leaq 1(%rsi), %rax
      ret
.LC:  movq $-1, %rax
      ret
.Ldef: movl $0, %eax
      ret
.Ltab: .quad .LA, .LB, .Ldef, .LA, .LC, .LB

(a) C switch로 옮기기 (case 값 포함) (b) f(13, 5), f(9, 5), f(14, 7), f(12, 99)의 값 (c) x < 10이어도 ja 하나로 처리되는 이유.

x = 11을 기준값 10만큼 빼서 jump table index를 만들면 index = 1 → 표의 1번 엔트리로 이동. 각 엔트리가 가리키는 case는 직접 대응시켜 보기.
힌트 보기
테이블 인덱스 = x − 최소 case. .quad 엔트리는 각 case 몸통의 label 주소. ja는 unsigned 비교라 음수 인덱스가 큰 양수로 보여 범위 검사 한 번에 걸러짐.
정답 보기
풀이
  1. index = x − 10. 표 대응: 0→A, 1→B, 2→default, 3→A, 4→C, 5→B
  2. (a) case 10·13 → 8×y (leaq 0(,%rsi,8)), case 11·15 → y+1, case 14 → −1, 나머지 → default 0 (case 12는 default)
  3. (b) f(13,5) = 8×5 = 40 · f(9,5): index = −1 → unsigned로는 매우 큼 → default 0 · f(14,7) = −1 · f(12,99) = 0
  4. (c) ja가 unsigned 비교라 음수 index가 큰 값으로 보여, 범위 검사 한 번으로 양쪽 끝을 다 처리
최종 답switch(x){ case 10: case 13: return 8*y; case 11: case 15: return y+1; case 14: return -1; default: return 0; } · 40, 0, −1, 0 · ja = unsigned 비교
