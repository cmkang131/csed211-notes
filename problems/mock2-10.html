Q10 · 구조체 접근 어셈블리 → C

모의고사 2탄 · 자작 · Lec7 Data — struct 필드 오프셋과 포인터 따라가기 · 8점

문제 10

다음 구조체와 어셈블리를 보고 물음에 답하시오. 

struct rec {
    long x;
    long arr[3];
    struct rec *next;
};
f:
    movq 32(%rdi), %rcx
    movq (%rcx), %rax
    movq 8(%rdi,%rsi,8), %rdx
    addq %rdx, %rax
    ret
(a) f의 C 코드를 복원하시오 (long f(struct rec *p, long i)). [4점]

(b) arr과 next의 오프셋, 그리고 sizeof(struct rec)을 쓰시오. [4점]

정답 보기
풀이
(a)
  1. movq 32(%rdi), %rcx → p->next (오프셋 32).
  2. movq (%rcx), %rax → p->next->x.
  3. movq 8(%rdi,%rsi,8), %rdx → p->arr[i] (long이라 scale 8, arr 시작 오프셋 8).
  4. addq → 두 값을 더해 반환.
    long f(struct rec *p, long i) {
    return p->next->x + p->arr[i];
}
(b)
  1. x@0 (8바이트) → arr@8 (long 3개 = 24바이트, 8~31) → next@32 (포인터 8바이트) → 총 40바이트, 8의 배수 조건도 만족.
최종 답arr=8, next=32, sizeof=40
