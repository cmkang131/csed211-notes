Q9 · 구조체 정렬

모의고사 2탄 · 자작 · Lec7 Data — struct alignment과 padding · 8점

문제 9

다음 구조체를 보고 물음에 답하시오. 

struct S {
    char c;
    long l;
    int i;
    char d;
};
(a) 각 필드의 오프셋을 쓰시오. [4점]

(b) sizeof(struct S)를 쓰고, 그 크기가 되는 이유를 한 줄로 설명하시오. [2점]

(c) 필드 순서를 바꿔 크기가 최소가 되게 재배열하고, 그 크기를 쓰시오. [2점]

정답 보기
풀이
(a)
  1. c@0 (1바이트) → 다음 필드 long은 8바이트 정렬이라 1~7 패딩 → l@8 (8바이트) → i@16 (4바이트) → d@20 (1바이트).
(b)
  1. 마지막 필드가 21에서 끝나지만, 구조체 크기는 최대 정렬 요구(long의 8)의 배수여야 하므로 끝에 3바이트 패딩 → 24.
(c)
  1. struct S { long l; int i; char c; char d; } → l@0, i@8, c@12, d@13, 끝 패딩 2바이트 → 16.
최종 답c=0, l=8, i=16, d=20 · 24 · 16바이트
