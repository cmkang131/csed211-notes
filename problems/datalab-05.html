Data Lab 연습 05

Data Lab · bitwise 연산 제한

문제 5

전제: 이 문제에서는 32비트 2의 보수 정수의 비트 패턴을 사용하고, 덧셈 결과는 32비트로 취한다. signed 정수의 오른쪽 시프트는 arithmetic right shift로 가정한다. 일반 ISO C에서는 signed int의 덧셈 결과가 표현 범위를 넘으면 동작이 정의되지 않으므로, 아래 계산은 이 문제에서 지정한 32비트 기계 모델을 따른다.

addOK 식 !(((x ^ s) & (y ^ s)) >> 31)(단, s = x + y)에 x = 0x60000000, y = 0x30000000을 넣어 결과를 구하라.

힌트 보기
signed overflow는 같은 부호끼리 더해 다른 부호가 나올 때만 발생. 부호 bit는 arithmetic >> 31로 꺼낸다 (결과는 0 또는 −1).
정답 보기
풀이
  1. s = x + y = 0x90000000 (MSB 1, 음수)
  2. x ^ s = 0xF0000000, y ^ s = 0xA0000000 → & = 0xA0000000
  3. MSB 1 → >> 31 = -1 → ! → 0: 양수 + 양수 = 음수 → overflow
최종 답0 (overflow)
