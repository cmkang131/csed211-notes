int f(int n)의 C 코드를 복원하고, f(5)와 f(-3)의 값을 구하라.

f(4) = 0+1+2+3 = 6, f(0) = 0 (반복문이 실행되지 않음). f(5), f(-3)은 직접 계산.

정답
  1. %eax = 0, %edx = 0 — 반환값과 counter 초기화

  3. .L2에서 %edx < %edi이면 .L3(몸통)으로 점프 — 조건은 i < n

struct node { long val; struct node *next; int arr[4]; };

g:  movq 8(%rdi), %rax
    movl 16(%rax,%rsi,4), %eax
    ret
h:  leaq 16(%rdi,%rsi,4), %rax
    ret

(%rdi = struct node *p, %rsi = long i). g와 h의 C 코드는?

현재 node의 arr = {1,2,3,4}, 다음 node의 arr = {10,20,30,40}, i = 2라면 각 배열의 원소 값은 3과 30. g는 값을, h는 특정 원소의 주소를 돌려준다는 차이를 확인.

03Recursion(재귀)과 callee-saved★★Lec6 · 프로시저 | Bomb Lab 연계
long fact(long n){ if (n <= 1) return 1; return n * fact(n-1); }

fact: cmpq $1, %rdi
      jg .L2
      movl $1, %eax
      ret
.L2:  pushq %rbx
      movq %rdi, %rbx
      leaq -1(%rdi), %rdi
      call fact
      imulq %rbx, %rax
      popq %rbx
      ret

(a) %rbx를 push하는 이유 (b) main이 fact(4)를 호출했을 때 가장 깊은 곳에서 스택에 쌓이는 바이트 수 (반환 주소 포함) (c) 각 frame이 저장한 %rbx의 값.

main → fact(2) → fact(1)이면 반환 주소가 두 번 저장되고 pushq %rbx는 fact(2)에서 한 번 실행됨. 사용량 8×2+8 = 24B.
힌트
call을 가로질러 값이 살아야 하면 caller-saved register는 못 씀 — callee-saved(%rbx 등)에 옮기되 원래 값은 push/pop으로 보존. frame 크기 = return address 8B + push한 register 8B씩.
정답
  1. (a) n을 재귀 호출 뒤 곱셈에 써야 하는데 %rdi는 caller-saved라 call 중에 바뀜 → callee-saved인 %rbx를 쓰려면 규약상 원래 값을 저장했다가 복원해야 함
  2. (b) fact(4), fact(3), fact(2) frame은 return address 8 + 저장된 rbx 8 = 16B씩, fact(1)은 push 없이 return address 8B만 → 16×3 + 8 = 56B
  3. (c) fact(4) frame이 저장한 rbx = main의 rbx, fact(3) frame = 4, fact(2) frame = 3
(a) %rdi가 caller-saved라서 (b) 56 byte (c) main의 rbx / 4 / 3 · 반환값은 4×3×2×1 = 24
04Data Lab 스타일 (허용 연산자 지키기)★★Lec2 · 비트 연산 | Data Lab 연계

(a) bitXor(x, y): ~와 &만 사용 (b) conditional(x, y, z): x ? y : z — ! ~ & ^ | + << >> 허용 (c) 부호 있는 int x를 8로 나눈 값(0 쪽으로 반올림)을 / 없이 (d) x × 15를 시프트와 덧셈·뺄셈으로.

힌트
De Morgan — x|y = ~(~x & ~y) · 모든 비트가 0이거나 1인 마스크: (!!x << 31) >> 31 · 음수 나눗셈은 bias를 더해야 0 쪽으로 반올림 · ×(2^k − 1) = (x<<k) − x.
정답
  1. (a) XOR = (x|y)에서 겹치는 비트를 뺀 것. |는 De Morgan으로 만들기: return ~(~x & ~y) & ~(x & y);
  2. (b) x가 참이면 mask = −1(전부 1), 거짓이면 0이 되게 하고 mask로 y·z 선택: int mask = (!!x << 31) >> 31; return (mask & y) | (~mask & z);
  3. (c) 음수일 때만 bias 2³−1 = 7을 더해야 0 쪽으로 반올림됨 — (x>>31)&7이 그 bias: return (x + ((x >> 31) & 7)) >> 3;
  4. (d) 15 = 16 − 1 → (x << 4) - x (즉 (x<<4) + ~x + 1)
(a) ~(~x & ~y) & ~(x & y) (b) (!!x<<31)>>31 마스크로 선택 (c) (x + ((x>>31) & 7)) >> 3 (d) (x<<4) − x
05Data Lab 스타일: float_twice (floatScale2)★★★Lec3 · 부동소수점 | Data Lab 연계

unsigned uf를 float 비트 패턴으로 보고 2×f의 비트 패턴을 반환하라. NaN이면 인자를 그대로 반환.

uf = 0x3F800000 (1.0f) → 0x40000000 (2.0f) · uf = 0x00000000 (+0.0f) → 그대로 · uf = 0x7FC00000 (NaN) → 그대로.
힌트
float = sign(1) + exp(8) + frac(23). exp == 0이면 비정규, exp == 0xFF면 특수(∞/NaN), 그 외 정규. 정규수에서 지수 +1 = 값 ×2. 비정규는 fraction을 한 칸 shift하면 됨.
정답
  1. 부호·지수·fraction을 분해: s = uf & 0x80000000, e = (uf>>23) & 0xFF, f = uf & 0x7FFFFF
  2. e == 0xFF (inf·NaN) → 그대로 반환 (NaN 조건 + inf는 2배해도 inf)
  3. e == 0 (비정규) → fraction을 shift: s | (f<<1) — 넘치는 비트가 지수로 올라가 자연스럽게 정규수로 전환
  4. e == 0xFE → 2배하면 지수가 0xFF가 되어 ∞: s | 0x7F800000
  5. 나머지 정규수 → 지수 +1: uf + 0x00800000
unsigned s = uf & 0x80000000, e = (uf >> 23) & 0xFF, f = uf & 0x7FFFFF;
if (e == 0xFF) return uf;             // inf 또는 NaN
if (e == 0)    return s | (f << 1);   // 비정규: fraction shift
if (e == 0xFE) return s | 0x7F800000; // 2배하면 무한대
return uf + 0x00800000;               // 지수 +1

08Condition Codes(조건 코드)★★Lec4·5 · 제어 흐름 | Bomb Lab 연계

%eax = 3일 때 cmpl $5, %eax, 그리고 %eax = 0x80000000일 때 cmpl $1, %eax. 각각 SF, ZF, CF, OF와 jl, jb, ja가 점프하는지 쓰라.

%eax = 2에서 cmpl $2, %eax는 2−2 = 0으로 flag만 갱신. ZF = 1이라 je는 점프함.
힌트
cmpl src, dst는 dst − src의 flag만 갱신 (결과 저장 없음). signed 비교는 SF^OF, unsigned는 CF가 기준. INT_MIN − 1은 signed overflow가 일어나는 대표 케이스.
정답
  1. 3 − 5 = −2 → SF = 1 (음수), ZF = 0, CF = 1 (unsigned 3 < 5라 borrow), OF = 0
  2. jl: SF≠OF → 점프 · jb: CF=1 → 점프 · ja: CF=1 → 점프 안 함
  3. INT_MIN − 1 = 0x7FFFFFFF (overflow) → SF = 0, ZF = 0, CF = 0, OF = 1
  4. jl: SF≠OF → 점프 (INT_MIN < 1이 맞음) · jb: CF=0 → 안 함 · ja: CF=0이고 ZF=0 → 점프
첫째: SF1 ZF0 CF1 OF0 — jl·jb 점프, ja 안 함 · 둘째: SF0 ZF0 CF0 OF1 — jl·ja 점프, jb 안 함

11덧셈 Overflow(오버플로) 검출★★★Lec2 · 비트 연산 | Data Lab 연계

int 두 개 x, y의 합이 오버플로 없이 표현되면 1, 아니면 0을 반환하는 함수를 연산자 제한 없이 작성하라.

(32-bit int 가정) x = 10, y = 20 → 합 30은 표현 가능 → 1 · x = INT_MAX, y = 1 → 오버플로 → 0. 일반 C에서 signed overflow 자체는 정의되지 않음.
힌트
오버플로는 x와 y의 부호가 같고 합의 부호가 다를 때만 발생. 부호 비트는 ^와 >> 31로 추출.
정답
  1. s = x + y (2의 보수 비트 패턴으로 계산)
  2. x ^ s의 부호 비트: x와 합의 부호가 다르면 1
  3. (x^s) & (y^s)의 부호 비트가 1 = 둘 다 합과 부호가 다름 = x, y 부호가 같고 합만 다름 = 오버플로
int s = x + y; return !(((x ^ s) & (y ^ s)) >> 31);
12반올림 (round-to-even)★★Lec3 · 부동소수점 | Data Lab 연계

같은 형식에서 1.125 = 1.001₂는 3비트 fraction에 정확히 들어가므로 0 0111 001.
