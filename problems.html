2. Lec2 · Bits, Bytes, Integer(정수)s (Data Lab 1 / 2 연계)

2-1 [자작] ★ 8-bit 2의 보수

x = 0xB4 (8-bit). (a) signed 값 (b) unsigned 값 (c) x >> 2 산술 시프트 결과(16진수와 10진수) (d) 논리 시프트 결과 (e) -x

정답

(a) 10110100 = -128+32+16+4 = -76. (b) 180. (c) 11101101 = 0xED = -19. (d) 00101101 = 0x2D = 45. (e) ~x+1 = 01001100 = 0x4C = 76.

2-2 [자작] ★★ C 비교 (int 32-bit, 2의 보수). true/false?

(1) -1 < 0U (2) (unsigned char)300 == 44 (3) (short)0x12348000 의 값 (4) INT_MIN == -INT_MIN (5) unsigned u = 3; int i = -4; u + i > 0

정답

(1) false : 0U 때문에 -1이 unsigned로 바뀌어 4294967295 < 0 이 됨. (2) true: 300 mod 256 = 44. (3) 하위 16비트 0x8000 이므로 -32768. (4) true: -INT_MIN은 오버플로로 자기 자신. (5) true: u + i 는 unsigned 연산, 3 + (2^32 - 4) = 2^32 - 1 > 0.

2-3 [자작] ★★ 4-bit 연산

4-bit 정수. (a) 0110 + 0101 을 signed로 해석한 결과와 오버플로 여부 (b) unsigned 1011 * 0011 의 4-bit 결과 (c) TMin, TMax, UMax (d) signed -3을 8-bit로 sign extension 한 값

정답

(a) 1011 = -5, 6+5=11이 TMax(7)를 넘으므로 오버플로. (b) 11*3=33, 33 mod 16 = 1 → 0001. (c) TMin=-8 (1000), TMax=7 (0111), UMax=15. (d) 1101 → 11111101 (0xFD).

2-4 [자작] ★★ Data Lab 스타일 (허용 연산자를 지켜서 풀기)

(a) bitXor(x,y) : ~ 와 & 만 사용 (b) conditional(x,y,z): x ? y : z, ! ~ & ^ | + << >> 허용 (c) 부호 있는 int x를 8로 나눈 값(0 쪽으로 반올림)을 / 없이 (d) x * 15 를 시프트와 덧셈 / 뺄셈으로

정답

(a) return ~(~x & ~y) & ~(x & y); (x|y 는 ~(~x&~y), XOR = (x|y) & ~(x&y))

(b) int mask = (!!x << 31) >> 31; return (mask & y) | (~mask & z);

(c) return (x + ((x >> 31) & 7)) >> 3; (음수일 때만 bias 7을 더해서 0 쪽 반올림)

(d) (x << 4) + ~x + 1 즉 (x<<4) - x

2-5 [자작] ★★★ 덧셈 Overflow(오버플로) 검출

int 두 개 x, y 의 합이 오버플로 없이 표현되면 1, 아니면 0을 반환하는 함수를 연산자 제한 없이 작성하기.

정답

int s = x + y;

return !(((x ^ s) & (y ^ s)) >> 31);

오버플로는 x와 y의 부호가 같고 합의 부호가 다를 때만 발생. (x^s) 와 (y^s) 의 부호 비트가 둘 다 1이면 그 경우.

3. Lec3 · Floating Point(부동소수점) (Data Lab 2 연계)

형식 (자작 공통) : 8-bit, 1 부호 / 4 지수 (bias = 7) / 3 fraction.

3-1 [자작] ★ 인코딩

(a) 6.5 (b) 0 0000 011 이 나타내는 값 (c) 가장 큰 유한 양수 (d) 가장 작은 양의 정규수 (e) 가장 작은 양의 비정규수 (f) +무한대

정답

(a) 6.5 = 110.1b = 1.101 x 2^2 → e = 2+7 = 9 = 1001, frac = 101 → 0 1001 101 (0x4D).

(b) 비정규 : E = 1-7 = -6, M = 3/8 → 3/8 x 2^-6 = 3/512.

(c) 0 1110 111 = 1.875 x 2^7 = 240. (d) 0 0001 000 = 2^-6. (e) 0 0000 001 = 1/8 x 2^-6 = 2^-9. (f) 0 1111 000.

3-2 [자작] ★★ 반올림 (round-to-even)

1.0625 (= 17/16) 와 1.1875 (= 19/16) 를 같은 형식으로 인코딩.

정답

1.0625 = 1.0001b. fraction 3비트 뒤에 남는 비트 "1"은 정확히 중간(tie) → 짝수 쪽 (마지막 비트 0) 선택 → 1.000 → 0 0111 000.

1.1875 = 1.0011b. 1.001|1 tie. 1.001 은 홀수 → 올림 → 1.010 = 1.25 → 0 0111 010.

3-3 [자작] ★★ C 의 float / double 성질 (true/false)

(1) int x = 16777217 (2^24+1) 에서 x == (int)(float)x (2) (1e20 + -1e20) + 3.14 == 1e20 + (-1e20 + 3.14) (double) (3) 0.1 + 0.2 == 0.3 (double) (4) float f; f == -(-f) 은 NaN이 아닐 때 항상 true? (5) int 로 변환한 (int)3.99 와 (int)-3.99

정답

(1) false : float 의 유효 숫자는 24비트라 2^24+1 은 표현 불가, 2^24 로 반올림. (2) false: 왼쪽은 3.14, 오른쪽은 3.14가 -1e20에 흡수되어 0. 결합법칙 불성립. (3) false (이진수로 정확히 표현 불가). (4) true (부호 비트만 두 번 뒤집음). (5) 3 과 -3 (0 쪽으로 절단).

3-3b [자작] ★★★ Data Lab 스타일: float_twice (floatScale2)

unsigned uf 를 float 비트 패턴으로 보고 2*f 의 비트 패턴을 반환. NaN 이면 인자를 그대로 반환.

정답

unsigned s = uf & 0x80000000;

unsigned e = (uf >> 23) & 0xFF;

unsigned f = uf & 0x7FFFFF;

if (e == 0xFF) return uf; // inf 또는 NaN

if (e == 0) return s | (f << 1); // 비정규: fraction 을 시프트 (넘치면 자연스럽게 정규수로 전환)

if (e == 0xFE) return s | 0x7F800000; // 2배하면 무한대

return uf + 0x00800000; // 지수 +1

4. Lec5 · Control (cmov / 루프 / Switch(스위치(switch)) / bomb lab 연계)

4-1 [자작] ★ asm 읽기 (cmov)

f:  cmpq %rsi, %rdi
    movq %rsi, %rax
    cmovl %rdi, %rax
    ret

x = %rdi, y = %rsi (long). f 는 무엇을 계산?

정답

cmp %rsi,%rdi 는 x - y 로 플래그 설정. x < y (signed) 이면 rax = x, 아니면 y. 즉 signed min(x, y).

4-2 [자작] ★★ while 루프 (jump-to-middle)

f:  movl $0, %eax
    movl $0, %edx
    jmp  .L2
.L3: addl %edx, %eax
    addl $1, %edx
.L2: cmpl %edi, %edx
    jl   .L3
    ret

int f(int n) 의 C 코드를 복원하고, f(5)와 f(-3)의 값을 구하기.

정답

int f(int n)\{ int sum = 0; for (int i = 0; i < n; i++) sum += i; return sum; \}

f(5) = 0+1+2+3+4 = 10, f(-3) = 0 (처음부터 i<n 이 거짓).

4-3 [자작] ★★ Condition Codes(조건 코드)

%eax = 3 일 때 cmpl $5, %eax, 그리고 %eax = 0x80000000 일 때 cmpl $1, %eax. 각각 SF, ZF, CF, OF 와 jl, jb, ja 가 점프하는지 쓰기.

정답

첫째 : 3-5 = -2 → SF=1, ZF=0, CF=1 (unsigned 3 < 5 이라 borrow), OF=0. jl 점프 (SF≠OF), jb 점프 (CF=1), ja 점프 안 함.

둘째 : INT_MIN - 1 = 0x7FFFFFFF (오버플로) → SF=0, ZF=0, CF=0, OF=1. jl 점프 (SF≠OF, 즉 INT_MIN < 1 이 맞음), jb 안 함, ja 점프 (CF=0 이고 ZF=0).

4-4 [자작] ★★★ Switch(스위치(switch)) / Jump(점프) 테이블 (bomb lab phase 3 같은 유형)

f:  subq $10, %rdi
    cmpq $5, %rdi
    ja   .Ldef
    jmp  *.Ltab(,%rdi,8)
.LA: leaq 0(,%rsi,8), %rax
    ret
.LB: leaq 1(%rsi), %rax
    ret
.LC: movq $-1, %rax
    ret
.Ldef: movl $0, %eax
    ret
.Ltab: .quad .LA, .LB, .Ldef, .LA, .LC, .LB

(a) C switch 로 복원 (case 값 포함) (b) f(13, 5), f(9, 5), f(14, 7), f(12, 99) 값 (c) x < 10 이어도 ja 하나로 처리되는 이유

정답

테이블 index = x-10. index0→A, 1→B, 2→default, 3→A, 4→C, 5→B.

(a) switch(x)\{ case 10 : case 13: return 8*y; case 11: case 15: return y+1; case 14: return -1; default: return 0; \} (case 12 는 default)

(b) f(13,5) = 8*5 = 40. f(9,5): index = -1 → unsigned 로는 매우 큼 → ja → 0. f(14,7) = -1. f(12,99) = 0.

(c) ja 는 unsigned 비교라서 음수 index 가 큰 양수로 보여서 범위 밖으로 처리됨. 범위 검사 한 번으로 양쪽 끝을 다 처리.

5. Lec6 · Procedure(프로시저)s (bomb lab Recursion(재귀) phase 연계)

5-1 [자작] ★ Stack(스택) Pointer(포인터) 추적 (x86-64)

call foo 직전 %rsp = 0x7fffffffe010. foo 안에서 push %rbp, sub $0x20, %rsp 를 실행. 다음 시점의 %rsp 는? (a) foo 첫 명령 직전 (b) push 직후 (c) sub 직후 (d) ret 직후 (정상 복귀 시, 스택 정리 완료 가정)

정답

(a) 0x7fffffffe008 (call 이 반환 주소 8바이트를 push). (b) 0x7fffffffe000. (c) 0x7fffffffdfe0. (d) 0x7fffffffe010 (ret 이 반환 주소를 pop 하고 8 증가, 그 전에 sub 와 push 는 되돌려 둔 상태).

5-2 [자작] ★ 인자 전달

long f(long a, int b, char *c, long d, long e, long g, long h). 각 인자는 어디에? 반환값은?

정답

a=%rdi, b=%esi, c=%rdx, d=%rcx, e=%r8, g=%r9, h=스택 (함수 진입 시점 8(%rsp), 0(%rsp)는 반환 주소). 반환값은 %rax.

5-3 [자작] ★★ Recursion(재귀)와 callee-saved

long fact(long n){ if (n <= 1) return 1; return n * fact(n-1); }

fact: cmpq $1, %rdi
      jg   .L2
      movl $1, %eax
      ret
.L2:  pushq %rbx
      movq  %rdi, %rbx
      leaq  -1(%rdi), %rdi
      call  fact
      imulq %rbx, %rax
      popq  %rbx
      ret

(a) %rbx 를 push 하는 이유 (b) main 이 fact(4) 를 호출했을 때 가장 깊은 곳에서 스택에 쌓이는 바이트 수 (반환 주소 포함) (c) 각 frame 이 저장한 %rbx 의 값

정답

(a) n 을 재귀 호출 뒤에 곱셈에 써야 하는데, %rdi 는 caller-saved 라 호출 중 바뀜. %rbx 는 callee-saved 라서 쓰려면 원래 값을 저장했다가 복원해야 함.

(b) fact(4), fact(3), fact(2) 는 각각 반환 주소 8 + 저장 rbx 8 = 16바이트, fact(1) 은 반환 주소 8만 (push 안 함) → 16*3 + 8 = 56바이트.

(c) fact(4) frame : main 의 %rbx, fact(3) frame: 4, fact(2) frame: 3. 반환값 4*3*2*1 = 24.

5-4 [자작] ★ Register(레지스터) 분류

callee-saved 는? 호출 후에 값이 바뀔 수 있는 것은? %rax, %rbx, %rcx, %rdx, %rsi, %rdi, %rbp, %r8~%r11, %r12~%r15, %rsp

정답

callee-saved : %rbx, %rbp, %r12~%r15 (%rsp 는 특수, 복귀 시 원래대로). caller-saved (호출로 바뀔 수 있음): %rax, %rcx, %rdx, %rsi, %rdi, %r8~%r11.

6. Lec7 · Data (Array(배열) / struct)

6-1 [자작] ★ 2차원 Array(배열) 주소

int A[5][3], A 의 시작 주소 0x1000. &A[3][2] 의 주소는? 그리고 아래 asm 은 어떤 함수인지 (M은 열 수)

get: leaq (%rsi,%rsi,2), %rax
     leaq (%rdi,%rax,4), %rax
     movl (%rax,%rdx,4), %eax
     ret
정답

주소 = 0x1000 + 4*(3*3 + 2) = 0x1000 + 44 = 0x102C.

asm : rax = 3*i, rax = A + 12*i (행 하나가 3 x 4바이트), 값 = *(A + 12i + 4j). 즉 int get(int A[][3], long i, long j)\{ return A[i][j]; \} (i = %rsi, j = %rdx).

6-2 [자작] ★★ struct Alignment(정렬) (x86-64)

struct S \{ char a; int b; short c; char d; long e; char f[3]; \};

(a) 각 필드 offset 과 sizeof(S) (b) sizeof 를 가장 작게 만드는 필드 순서와 그 크기

정답

(a) a:0, b:4, c:8, d:10, e:16, f:24~26, 끝 27 인데 전체 정렬이 8 이라 size = 32.

6-3 [자작] ★★ struct 접근 asm

struct node \{ long val; struct node *next; int arr[4]; \};

g:  movq 8(%rdi), %rax
    movl 16(%rax,%rsi,4), %eax
    ret
h:  leaq 16(%rdi,%rsi,4), %rax
    ret

(rdi = struct node *p, rsi = long i). g 와 h 의 C 코드는?

정답

offset : val 0, next 8, arr 16.

g : int g(struct node *p, long i)\{ return p->next->arr[i]; \}

h : int *h(struct node *p, long i)\{ return &p->arr[i]; \} (leaq 는 메모리를 읽지 않고 주소만 계산)

6-4 [자작] ★ Pointer(포인터) 연산

int *p = (int *)0x1000; char *q = (char *)0x1000; long *r = (long *)0x1000. p+3, q+3, r+3 의 값? 그리고 *(p+2) 와 같은 배열 표기는?

정답

p+3 = 0x100C, q+3 = 0x1003, r+3 = 0x1018. *(p+2) = p[2].

7. LAB 연계 (시험에 나올 수 있다고 한 부분)

Data Lab (= Lec2, Lec3)

  • 위 2-4, 2-5, 3-3b 가 직접 연습용. 랩에서 막혔던 함수가 있으면 허용 연산자 제한을 다시 걸고 새로 풀어보기.
  • 체크리스트: ~, ^ 로 부정 / 마스크 만들기 ((x << 31) >> 31), 산술 시프트와 논리 시프트 차이, TMin 특수 케이스(-TMin == TMin), float 의 e = 0 / 0xFF 케이스.

Bomb Lab (= Lec4~7)

  • 4-4 (switch 점프 테이블) = phase 3 유형. 5-3 (재귀) = phase 4 유형. 6-1, 6-3 (배열 / struct 접근) = phase 5, 6 (배열, 링크드 리스트) 유형.
  • 연습 방법: 문제의 asm 을 보고 (1) 인자가 어떤 레지스터인지 (2) 비교 / 점프로 만들어지는 구조 (3) 메모리 접근의 offset 과 scale 을 순서대로 적고 C 로 복원. 시험에서 asm 복원 문제의 풀이 순서와 같음.
  • gdb 명령 암기: break explode_bomb, disas, x/s ADDR, x/8gx $rsp, info registers, stepi / nexti.
