문제 풀이

자작 21 + Data Lab 8 + Bomb Lab 6 + 모의고사 2탄 12 = 47문제. 문제마다 ▸힌트 / ▸정답 토글. 외부 기출·보조 링크는 맨 아래.

0읽기 전에

  • 각 문제는 먼저 풀고, 힌트·정답을 열어 확인. 힌트는 필요한 개념만, 정답은 풀이와 답만 들어 있음
  • 난이도: ★ 기본 / ★★ 시험 수준 / ★★★ 응용
  • 출처 표기: [자작] = 직접 작성한 문제 / [기출] = CMU 15-213 공개 기출 원문 PDF 링크 (CSAPP 저자 강의, 이 과목과 같은 계열 — 변형 아닌 원문) / [보조] = LeetCode 비트 감각용
  • 실수 자작 문제(12, 16번)의 공통 형식: 8-bit, 부호 1 / 지수 4 (bias = 7) / fraction 3
  • CMU 옛 기출 일부는 32-bit(IA32) 코드. 이 과목은 x86-64 기준. 레지스터 이름뿐 아니라 인자 전달·포인터 크기·스택 규약이 다를 수 있으니 해당 문제의 가정을 따를 것
  • 정수 자작 문제는 32-bit 비트벡터(Data Lab) 모델로 볼 것. 표준 C에서 signed overflow는 undefined이므로 14·11번의 코드를 일반 C 규칙과 혼동하지 말 것
  • LeetCode에는 Data Lab의 허용 연산자 제한이 자동 적용되지 않음. 같은 문제를 "허용 연산자만 써서" 다시 풀면 랩 연습이 됨
  • 정답은 원본 노트를 옮겨 재정리한 것 (전면 재검산 판은 아님)
  • LAB 표시는 개념상 연계. Bomb Lab 실제 phase 코드와 같다는 뜻이 아님

CLAB 복습 메모 (시험에 나올 수 있다고 한 부분)

Data Lab (= Lec2, Lec3)

  • 직접 연습용: 위 04, 05, 11번. 랩에서 막혔던 함수가 있으면 허용 연산자 제한을 다시 걸고 새로 풀어보기
  • 체크리스트: ~, ^로 부정·마스크 만들기 ((x << 31) >> 31) · 산술 시프트와 논리 시프트 차이 · TMin 특수 케이스 (−TMin == TMin) · float의 e = 0 / e = 0xFF 케이스

Bomb Lab (= Lec4~7)

  • 유형 대응: 06번(switch 점프 테이블) = phase 3 · 03번(재귀) = phase 4 · 09·02번(배열/struct 접근) = phase 5, 6 (배열, 링크드 리스트)
  • asm → C 옮기기 연습 순서 (시험 풀이 순서와 같음): (1) 인자가 어떤 register인지 (2) 비교·점프로 만들어지는 구조 (3) 메모리 접근의 offset과 scale을 순서대로 적고 C로 옮기기
  • gdb 명령 암기: break explode_bomb, disas, x/s ADDR, x/8gx $rsp, info registers, stepi / nexti
문제 풀이의 자작 문제는 강의 노트와 CS:APP/15-213 유형에서 직접 만든 것(기출 아님). 외부 링크의 해설은 각 사이트 소유.
