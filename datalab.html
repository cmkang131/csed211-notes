  • hex → binary는 자리마다 4 bit로 바꾸면 끝: b = 1011, 9 = 1001

Bitwise(비트 연산) vs Logical(논리) operator — 혼동 금지

  • bitwise (~ & | ^)는 bit pattern의 각 bit에 적용 / logical (&& || !)는 결과가 항상 0 또는 1
  • 예: bitwise 0x69 & 0x55 = 0x41 이지만 logical 0x69 && 0x55 = 1 · ~0x55 = 0xAA (8-bit) 이지만 !0x55 = 0
  • assignment 버전: &= |= ^= <<= >>= (a &= b → a = a & b)

  • AND: 둘 다 1일 때 1 · OR: 하나라도 1이면 1 · XOR: 둘 중 하나만 1일 때 1 · NOT: 0 ↔ 1
  • bit vector에 bitwise로 적용 → Boolean algebra의 성질이 모두 성립 (De Morgan 포함)

De Morgan — lab에서 직접 쓰게 됨

Shift(시프트)

  • left shift x << y: 왼쪽으로 y칸, 오른쪽은 0으로 채움 — 위로 밀려난 bit는 사라짐
  • right shift x >> y: logical은 왼쪽을 0으로, arithmetic은 sign bit로 채움
  • C에서 >>는 operand type에 따라 다름: unsigned → logical, signed → arithmetic

3Data Lab 1 문제 풀이 (정수 6개)

Q0 minusOne (수업 예제) — -1 반환 · 허용 ! ~ & ^ | + << >> · 최대 2 ops

  • 허용 연산에 -가 없으니 return -1;은 규칙 위반 → -1의 bit pattern(모든 bit 1)은 0을 반전한 것
int minusOne(void) { return ~0; }  /* 1 op */

허용된 연산의 조합으로 원하는 bit pattern을 만드는 것이 lab의 기본 패턴.

Q1 bitNor(x, y) — ~(x|y) · 허용 ~ & · 최대 8 ops

  • 허용 연산에 |가 없음 → De Morgan으로 |를 ~와 &로 바꿈
int bitNor(int x, int y) { return ~x & ~y; }  /* 3 ops */

Q2 isZero(x) — x가 0이면 1 · 최대 2 ops

  • !x는 x가 0이면 1, 아니면 0 — 정의와 정확히 일치. bitwise ~가 아니라 logical !를 써야 함 (~0은 -1)
int isZero(int x) { return !x; }  /* 1 op */

Q3 addOK(x, y) — x+y가 overflow 없이 계산되면 1 · 최대 20 ops

  • signed overflow는 x와 y의 부호가 같은데 합 s의 부호가 다를 때만 발생 — 부호가 다른 두 수의 합은 절대 overflow 안 됨
  • x ^ s의 MSB = 1 ⇔ x와 s 부호가 다름 → (x ^ s) & (y ^ s)의 MSB = 1 ⇔ overflow
  • >> 31은 signed라 arithmetic → 결과는 0 또는 -1 → !로 1/0 변환
int addOK(int x, int y) {
  int s = x + y;
  return !(((x ^ s) & (y ^ s)) >> 31);  /* + ^ ^ & >> ! : 6 ops */
}

손계산 4: x = 0x7FFFFFFF, y = 1 → s = 0x80000000, (x^s)&(y^s) = 0x80000001 → MSB 1 → 0 (overflow) · x = TMin, y = -1 → 0 (overflow) · x = 100, y = -200 → (x^s)&(y^s) = 0x000000A0 → 1 · x = y = 0x40000000 → 0xC0000000 → 0 (overflow)

Q4 absVal(x) — 절댓값 · 최대 10 ops

  • m = x >> 31 (arithmetic) → x ≥ 0이면 0, x < 0이면 -1 (모든 bit 1) — 분기 없이 부호에 따라 연산을 고르는 sign mask 기법
  • m = 0: (x + 0) ^ 0 = x · m = -1: (x - 1) ^ (전부 1) = ~(x - 1) = -x
int absVal(int x) {
  int m = x >> 31;
  return (x + m) ^ m;  /* >> + ^ : 3 ops */
}

손계산 5: x = 5 → m = 0 → 5 · x = -5 → m = 0xFFFFFFFF, x+m = -6, ^ m → 5 · x = TMin → 절댓값 2³¹은 int로 표현 불가 → TMin 그대로 (C의 -TMin과 같은 결과)

Q5 logicalShift(x, n) — n칸 logical right shift · 최대 20 ops

  • signed int의 >>는 arithmetic → x가 음수면 왼쪽이 1로 채워짐 → shift 후 위쪽 n bit를 0으로 만드는 mask를 AND
  • mask: (1 << 31) >> n (arithmetic)이면 위쪽 n+1 bit가 1 → 한 칸 더 밀어(<< 1) 위쪽 n bit만 1로 만든 뒤 ~
  • >> (n+1)로 한 번에 밀지 않는 이유: n = 31이면 shift 양이 32 → C에서 정의되지 않은 동작
  • n = 0이면 (0x80000000 >> 0) << 1 = 0 → mask = ~0 = 전부 1 → 그대로 통과
int logicalShift(int x, int n) {
  int mask = ~(((1 << 31) >> n) << 1);
  return (x >> n) & mask;  /* 6 ops */
}

손계산 6 — logicalShift(-16, 2): x = 0xFFFFFFF0 → x >> 2 = 0xFFFFFFFC · (1<<31) >> 2 = 0xE0000000 → << 1 = 0xC0000000 → mask = 0x3FFFFFFF · 결과 0xFFFFFFFC & 0x3FFFFFFF = 0x3FFFFFFC (unsigned 계산과 일치)

FP 문제 공통 접근 (보충) — uf를 세 field로 분리해 놓고 생각

sign = uf >> 31;  exp = (uf >> 23) & 0xFF;  frac = uf & 0x7FFFFF;
  • 먼저 exp == 0xFF (NaN/∞), exp == 0 (denorm/0), 그 외 (normalized)로 경우를 나눔
  • abs: sign bit만 0인 수 — NaN 입력은 그대로 돌려줘야 하는지 명세 확인
  • twice: normalized는 exp + 1 (결과가 0xFF면 ∞) · denorm은 frac을 한 칸 왼쪽으로 (넘치면 자연스럽게 normalized로) · NaN/∞는 그대로
  • i2f: 0과 TMin 특별 취급 · 절댓값의 최상위 1 위치로 E 결정 · 23 bit 넘는 부분은 round-to-even
  • f2i: E < 0이면 0 · int 범위 초과·NaN·∞이면 0x80000000 · 그 외는 1.f를 E만큼 shift 후 sign 적용

Two's complement 복습 (자세한 건 Lec2)

범위와 inversion

(양수 쪽에 대응 값이 없음) · 4-bit 예: 1000 = −8, 1011 = −5, 1111 = −1
  • TAdd와 UAdd는 bit 수준 동작이 동일 — w-bit 두 수의 진짜 합은 w+1 bit인데 carry를 버리고 w bit만 남김 → (int)((unsigned)u + (unsigned)v)와 u + v는 항상 같음

IEEE 754 복습 (자세한 건 Lec3)

  • 형식 · s: sign bit · exp field e: E를 encoding (E와 같지 않음) · frac field f: M을 encoding (M과 같지 않음)
  • single: s 1, exp 8, frac 23, bias 127 · double: s 1, exp 11, frac 52, bias 1023 · extended (Intel 80-bit): s 1, exp 15, frac 63/64
  • normalized: exp가 00…0도 11…1도 아님 → E = exp − Bias, M = 1.f (implied leading 1 — 맨 앞 1을 저장하지 않아 1 bit를 공짜로)
  • denormalized: exp = 00…0 → E = 1 − Bias, M = 0.f → 0 (f = 0, +0/−0 구분)과 0에 아주 가까운 수 (gradual underflow)
  • special: exp = 11…1 → f = 0이면 ±∞ (1.0/0.0), f ≠ 0이면 NaN (sqrt(−1), ∞−∞, ∞×0)
  • denorm의 E가 −Bias가 아니라 1 − Bias인 이유: 가장 큰 denorm과 가장 작은 normalized 사이가 끊김 없이 이어지게 하려고

6시험 포인트

Data Lab에서 시험에 나올 수 있는 것

  • bitwise (~ & | ^)는 bit마다, logical (! && ||)은 결과가 항상 0/1
  • C의 >>: unsigned → logical, signed → arithmetic — 8-bit 예: 10100010 >> 2 → logical 00101000, arithmetic 11101000
  • De Morgan → bitNor의 핵심
  • 규칙: 상수 0~255, 제어문·macro·함수 호출·int 외 type 금지, -와 && || 금지 (정수 문제)
  • −1 = ~0 · TMin = 1 << 31 ·
  • overflow 판정: 같은 부호끼리 더했는데 결과 부호가 다를 때
  • sign mask x >> 31 (0 또는 −1)로 분기 없이 연산 선택 · TMin의 절댓값은 표현 불가 → TMin
